    7. Inheritance¶

    1. Defining Inheritance¶

    When you hear "inheritance", you probably think of inheriting money or a house from your parents.

    Class inheritance is similar.

    Say there's an old class that can work out averages. Now there's a new class that also needs to work out averages. We can use inheritance: the new class inherits from the old class, and then the new class has that ability too.

    Usually, we call the old class the parent class and the new class the child class.

    First, let's look at the basic syntax of inheritance:

    class ClassName(BaseClassName):
    <statement-1>
    .
    .
    .
    <statement-N>

    When you define a class, you put the class it inherits from in the brackets. If you're not inheriting from anything, you can still write object, because in Python object is the parent of every class.

    The example above is single inheritance. Python also supports multiple inheritance. The syntax is:

    class ClassName(Base1,Base2,Base3):
    <statement-1>
    .
    .
    .
    <statement-N>

    One thing to note with multiple inheritance: if the parent classes have methods with the same name, and the child class doesn't say which one to use, Python searches the parent classes from left to right, in the order they're written in the brackets. That is, if a method isn't found in the child class, Python looks for it in the parent classes from left to right.

    So what can a child class do?

    Benefits of a child class: * It inherits the parent class's attributes and methods * It can define its own, and override the parent's attributes and methods

    2. Calling the Parent Class's Methods¶

    Once a class inherits from a parent, it can call the parent's methods directly. In the example below, UserInfo2 inherits from the parent class UserInfo, and can call the parent's get_account method directly.

    #!/usr/bin/env python
# -*- coding: UTF-8 -*-

class UserInfo(object):
    lv = 5

    def __init__(self, name, age, account):
        self.name = name
        self._age = age
        self.__account = account

    def get_account(self):
        return self.__account


class UserInfo2(UserInfo):
    pass


if __name__ == '__main__':
    userInfo2 = UserInfo2('Two Drops', 23, 347073565);
    print(userInfo2.get_account())

    3. Overriding a Parent Class's Method¶

    Of course, a child class can also override (rewrite) a parent class's method.

    Example:

    #!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class UserInfo(object):
    lv = 5

    def __init__(self, name, age, account):
        self.name = name
        self._age = age
        self.__account = account

    def get_account(self):
        return self.__account

    @classmethod
    def get_name(cls):
        return cls.lv

    @property
    def get_age(self):
        return self._age


class UserInfo2(UserInfo):
    def __init__(self, name, age, account, sex):
        super(UserInfo2, self).__init__(name, age, account)
        self.sex = sex;


if __name__ == '__main__':
    userInfo2 = UserInfo2('Two Drops', 23, 347073565, 'Male');
    # Print all attributes
    print(dir(userInfo2))
    # Print the attributes set in the constructor
    print(userInfo2.__dict__)
    print(UserInfo2.get_name())

    Output:

    ['_UserInfo__account', '__class__', '__delattr__', '__dict__', '__dir__', '__doc__', '__eq__', '__format__', '__ge__', '__getattribute__', '__gt__', '__hash__', '__init__', '__init_subclass__', ...]
{'name': 'Two Drops', '_age': 23, '_UserInfo__account': 347073565, 'sex': 'Male'}
5

    Here we've overridden the parent class's constructor.

    4. Checking the Type of a Child Class¶

    With class inheritance, sometimes we need to check what type a class is. How do we do that?

    We can use the isinstance() function.

    One example is enough to show how isinstance() works:

    #!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class User1(object):
    pass


class User2(User1):
    pass


class User3(User2):
    pass


if __name__ == '__main__':
    user1 = User1()
    user2 = User2()
    user3 = User3()
    # isinstance() tells us whether an object is a certain type
    print(isinstance(user3, User2))
    print(isinstance(user3, User1))
    print(isinstance(user3, User3))
    # isinstance() works on basic types too
    print(isinstance('Two Drops', str))
    print(isinstance(347073565, int))
    print(isinstance(347073565, str))

    Output:

    True
True
True
True
True
False

    You can see isinstance() not only tells us whether an object is a certain type – it also works on basic types.
