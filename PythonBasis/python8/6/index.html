    6. The Initialisation Function¶

    1. What is the Initialisation Function?¶

    The initialisation function is a function that is called automatically when you create an instance.

    For example:

    class ClassA(object):

    def __init__(self):
        print('Instance created')


# Instantiate
a = ClassA()

    Output (we didn't call the init method ourselves – it printed as soon as we created the instance):

    Instance created

    When the code runs a = ClassA(), it automatically calls the __init__(self) function.

    This __init__(self) function is the initialisation function, also called the constructor.

    The initialisation function always has the same form: init in the middle, meaning "initialise", with two underscores before and after. Inside the brackets of __init__(), the first parameter must be self, or you'll get an error.

    The constructor (initialisation function) looks like this:

    def __init__(self,[...):

    The initialisation function can take arguments too. For example:

    class ClassA(object):

    def __init__(self, str):
        print('Instance created')
        print(str)


# Instantiate
a = ClassA('Hello, I am a new object!')

    Output:

    Instance created
Hello, I am a new object!

    2. The Destructor¶

    Since the constructor is called when an object is created, it makes sense that when an object is destroyed, the destructor is called.

    The destructor's syntax:

    def __del__(self,[...):

    Here's an example:

    class ClassA(object):

    def __init__(self):
        print('Instance created')

    def __del__(self):
        print('Instance destroyed')


a = ClassA()
del a  # This destroys the object

    Output:

    Instance created
Instance destroyed

    3. An Old Leftover Problem with Defining Classes in Python¶

    As Python changed over its versions, it left behind an old problem with classes: new-style classes and old-style classes. Look at this code first:

    #!/usr/bin/env python
# -*- coding: UTF-8 -*-

# Old-style class
class OldClass:
    pass

# New-style class
class NewClass(object):
    pass

    These define classes in two different ways. The biggest difference is that the new-style class inherits from the object class. In Python 2, it was best to always define new-style classes. In Python 3 this problem doesn't exist any more, because all classes in Python 3 are new-style.

    So what's the difference between new-style and old-style classes?

    Run this code:

    #!/usr/bin/env python
# -*- coding: UTF-8 -*-

# Old-style class
class OldClass:
    def __init__(self, account, name):
        self.account = account
        self.name = name


# New-style class
class NewClass(object):
    def __init__(self, account, name):
        self.account = account
        self.name = name


if __name__ == '__main__':
    old_class = OldClass(111111, 'OldClass')
    print(old_class)
    print(type(old_class))
    print(dir(old_class))
    print('\n')
    new_class = NewClass(222222, 'NewClass')
    print(new_class)
    print(type(new_class))
    print(dir(new_class))
