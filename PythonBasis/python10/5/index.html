    5. Custom Containers¶

    From earlier chapters, we know Python's common container types are: dict, tuple, list and string. We also talked about mutable and immutable containers. Tuples and strings are immutable containers; dicts and lists are mutable containers.

    The difference is that once an immutable container is created, you can't change any of its elements. For more details, look back at the earlier articles, which have pictures.

    So here's a question: are these data structures enough for everything we need?

    What if they're not – what if some special need can't be met with just these basic containers?

    Then we need to make our own custom container. How do we do that?

    Goal What you need
    A custom immutable container type Define __len__ and __getitem__
    A custom mutable container type On top of the immutable ones, also define __setitem__ and __delitem__
    Your custom data type needs to be iterable Define __iter__
    Return the length of your custom container Write __len__(self)
    Your container can use self[key]. If key is the wrong type, raise TypeError. If there's no value for key, raise ValueError Write __getitem__(self, key)
    When self[key] = value runs It calls __setitem__(self, key, value)
    When del self[key] runs It actually calls __delitem__(self, key)
    When you want your container to work with for x in container: or iter(container) Write __iter__(self), which returns an iterator

    Let's use these magic methods to build a data structure from the Haskell language:

    #!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class FunctionalList:
    ''' Works like the built-in list type, plus some extra methods: head, tail, init, last, drop, take'''

    def __init__(self, values=None):
        if values is None:
            self.values = []
        else:
            self.values = values

    def __len__(self):
        return len(self.values)

    def __getitem__(self, key):
        return self.values[key]

    def __setitem__(self, key, value):
        self.values[key] = value

    def __delitem__(self, key):
        del self.values[key]

    def __iter__(self):
        return iter(self.values)

    def __reversed__(self):
        return FunctionalList(reversed(self.values))

    def append(self, value):
        self.values.append(value)

    def head(self):
        # Get the first element
        return self.values[0]

    def tail(self):
        # Get everything after the first element
        return self.values[1:]

    def init(self):
        # Get everything before the last element
        return self.values[:-1]

    def last(self):
        # Get the last element
        return self.values[-1]

    def drop(self, n):
        # Get everything except the first n elements
        return self.values[n:]

    def take(self, n):
        # Get the first n elements
        return self.values[:n]
