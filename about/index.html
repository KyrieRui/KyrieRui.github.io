About this site

Python for Beginners is a simple-English edition of walter201230/Python (小白学 Python), a free Chinese Python tutorial by walter201230 (“Two Drops”). Its layout follows the original interactive site, learn-py.org.

Every chapter has two modes:

  • Challenge mode – read a part, then write code in the editor. Click Run to see the output and Check answer to have it marked. Get an exercise right to unlock the next part.
  • Full read – the whole chapter on one page, for reading through or looking something up.

Your code runs in your own browser with Pyodide (Python 3.12 compiled to WebAssembly). Nothing is sent to a server, and you don't need an account. Your progress is saved only in this browser.
