1. A Quick Look at Python Syntax

Every language has its own grammar (syntax) – both human languages (like English and Chinese) and computer programming languages.

Python is no different. It has its own syntax rules. The interpreter takes code that follows these rules, turns it into machine code that the CPU can run, and then runs it.

Python's syntax is fairly simple. It uses indentation (spaces at the start of a line).

Python· Runs on this page
Practise on the challenge page →
# Check whether a number is positive (or zero)
a = 88
if a >= 0:
    print('yes')
else:
    print('NO')

Output:

Text
yes

In the code above, a line starting with # is a comment. Every other line is a statement. When a statement ends with a colon :, the indented lines below it form a code block.

Note that Python is case-sensitive. If you use the wrong capital or small letter, the program will give an error.

For more details, see the earlier article: Quick Overview of Python Code Style

2. The print() Function

Let's start with the print() function. If you are new, you may not know much about functions yet. That's fine. For now, you only need to know its parts and what it does. We will explain functions in detail later.

The print() function has two parts:

  1. The command: print
  2. What the command works on: the stuff inside the brackets after print

It looks like this:

The job of print() is to make the computer show a result on the screen (in the terminal). What it shows is whatever you put inside print().

For example, in the last chapter, our first Python program was print('Hello Python')

Python· Runs on this page
Practise on the challenge page →
print('Hello Python')

Output:

Text
Hello Python

Here is what happens step by step:

  1. You give the interpreter a command: print 'Hello Python'
  2. The interpreter turns your code into machine language the computer can understand
  3. The computer runs it and prints the result

Here is a picture of the process:

Some of you may ask: why do we need the single quotes? Can't we just write print(Hello Python)?

When you have a question like this while coding, the best thing to do is write the code and test it yourself.

Python· Syntax only
print(Hello Python)

Result:

Text
  File "test.py", line 1
    print(Hello Python)
                    ^
SyntaxError: invalid syntax

Clearly, without the quotes, the result turns red (an error). So this doesn't work.

This is because it breaks Python's syntax rules. Without the quotes, the Python interpreter can't understand what you wrote.

So it shows the error SyntaxError: invalid syntax, which means: syntax error. Your statement doesn't follow the rules.

3. Python's Basic Data Types

1. Strings

A string is one of the most common data types in Python. It is easy to spot: a string is text inside quotes.

You can use single quotes ' ', double quotes " " or triple quotes ''' '''. For example: 'abc', "123" and so on.

Please note: the quotes '' or "" are only a way to show where the string starts and ends. They are not part of the string. So the string 'abc' has only 3 characters: a, b and c.

If you like to think things through, you might ask:

Why do we need single quotes ' ', double quotes " " and triple quotes ''' '''? Why not just pick one? Why have so many rules for the same thing?

Good question. Usually, one rule for one thing is best. So if strings have three ways to be written, there must be a reason.

Let's write the same string in all three ways, print them, and see what happens.

Python· Runs on this page
Practise on the challenge page →
str1 = 'Sam'
str2 = "Sam"
str3 = '''Sam'''
print(str1)
print(str2)
print(str3)

The results are the same:

Text
Sam
Sam
Sam

But what if our string is not Sam, but Sam's book – with a quote mark inside it?

Then we get an error straight away:

Python· Read with the text above
str1 = 'Sam's book'
print(str1)
Text
  File "test.py", line 1
    str1 = 'Sam's book'
                  ^
SyntaxError: invalid syntax

Notice: single quotes ' ' don't work here, but double quotes " " do.

Python· Runs on this page
Practise on the challenge page →
str2 = "Sam's book"
print(str2)

The result is just what we wanted:

Text
Sam's book

Triple quotes work the same way. If your text has double quotes inside it, double quotes around it will give the same error. That is when you can use triple quotes:

Python· Runs on this page
Practise on the challenge page →
str3 = '''Sam said: "Hello!"'''
print(str3)
Text
Sam said: "Hello!"

So, can strings made with single or double quotes never hold text like this?

They can! You can use escape characters.

For a single quote, write \'. For a double quote, write \".

Be careful: this is a backslash \, not a forward slash /.

Now let's test it:

Python· Runs on this page
Practise on the challenge page →
str1 = 'Sam\'s book'
str2 = "Sam said: \"Hello!\""
print(str1)
print(str2)

The output:

Text
Sam's book
Sam said: "Hello!"

One last thing: triple quotes ''' ''' let a string go over several lines.

Python· Runs on this page
Practise on the challenge page →
str2 = '''Sam
loves
Python'''
print(str2)

Output:

Text
Sam
loves
Python

2. Integers

An integer in code is the same as an integer in maths: positive whole numbers, negative whole numbers and zero. Integers are numbers without a decimal point.

Python can handle integers of any size, for example 1, 100, -8080, 0 and so on.

Python· Runs on this page
Practise on the challenge page →
int1 = 1
int2 = 100
int3 = -8080
int4 = 0

print(int1)
print(int2)
print(int3)
print(int4)

Output:

Text
1
100
-8080
0

Be careful: if you put a number inside quotes, it becomes a string, not an integer. For example, '100' is a string, not an integer.

In real life we do maths with whole numbers. In code it's the same: you can add, subtract, multiply and divide integers.

For example:

Python· Runs on this page
Practise on the challenge page →
int1 = 1 + 2
int2 = 1 - 2
int3 = 1 * 2
int4 = 1 / 2

print(int1)
print(int2)
print(int3)
print(int4)

Output:

Text
3
-1
2
0.5

Now look at the example above. Do you notice anything?

Look at what int4 prints: 0.5. That is a decimal number.

And how did we define an integer earlier?

A number without a decimal point.

So int4 is definitely not an integer.

We can use the type() function to check the type:

Python· Runs on this page
Practise on the challenge page →
int1 = 1 + 2
int2 = 1 - 2
int3 = 1 * 2
int4 = 1 / 2

print(int1)
print(int2)
print(int3)
print(int4)

print(type(int1))
print(type(int2))
print(type(int3))
print(type(int4))

Result:

Text
3
-1
2
0.5
<class 'int'>
<class 'int'>
<class 'int'>
<class 'float'>

We can see that int4 is a float, while int1, int2 and int3 are all int (integer).

So what is a float?

A float is a floating-point number. We will talk about it next.

Before that, have a quick look at Python's arithmetic operators, just to get to know them.

Python Arithmetic Operators

Operator Meaning Example
+ Add 2 + 1 gives 3
- Subtract 1 - 2 gives -1
* Multiply 1 * 2 gives 2
/ Divide 1 / 2 gives 0.5
% Modulo – gives the remainder of a division 5 % 2 gives 1
** Power – gives x to the power of y 2 ** 3 is 2 to the power of 3
// Floor division – gives the whole-number part of the answer 11 // 2 gives 5, 11.0 // 2.0 gives 5.0

3. Floats

A float is a number with a decimal point.

Floats are like integers in many ways, but floats are the trickiest. They are the hardest to fully understand.

The famous programmer Herb Sutter once joked that there are three kinds of people: people who know they don't understand floating-point maths; people who think they understand it; and a very small number of experts who wonder if they could ever fully understand it.

Why would he say that?

Look at the example below. Just like with integers, we are only adding some floats:

Python· Runs on this page
Practise on the challenge page →
print(0.55+0.41)
print(0.55+0.4)
print(0.55+0.411)

But the results might surprise a beginner:

Text
0.96
0.9500000000000001
0.9610000000000001

The first one is fine: 0.55 + 0.41 equals 0.96, exactly right. But in the other two, where did all those zeros come from?

This is because computers cannot store floats perfectly. Computers save numbers in binary, and binary cannot show some numbers exactly. It can only get very, very close.

So be careful when you do maths with floats or compare them.

4. Booleans

Booleans work just like in Boolean algebra. A Boolean has only two values: True or False. It is always one or the other. In Python you can write True and False directly (watch the capital letters!), or you can get them from a Boolean calculation.

You can use and, or and not with Booleans.

and: the result is True only if all parts are True.

or: the result is True if at least one part is True.

not: it works on just one value. It turns True into False, and False into True.

5. None (the empty value)

Almost every programming language has a special "empty" value. In Python, it is called None.

6. f-strings: putting variables inside strings

Hey everyone! What if you want to put the value of a variable inside some text? How do you do it?

The best way in Python is called an f-string (added in Python 3.6). Put an f before the opening quote, and wrap a variable name in {} inside the string. Python will replace the {} with the variable's value.

Python· Runs on this page
Practise on the challenge page →
name = 'Sam'
print(f'Nickname: {name}')

Output:

Text
Nickname: Sam

It's that simple: f at the front + {variable_name}. Single or double quotes both work, and you can use many {} in one string. This is the recommended way to build strings today.

Now that you know the basics, here are a few more advanced tricks that many people don't know about.

(1) Self-documenting: a great debugging tool f"{x=}"

When you write code, do you often want to print a variable's name and value to help find bugs?

The old way looks like this:

Python· Runs on this page
Practise on the challenge page →
name = 'Sam'
age = 18

print(f'name={name}, age={age}')

Output:

Text
name=Sam, age=18

You have to type each variable name twice, and if you rename a variable, it's easy to forget one. Since Python 3.8, f-strings have an = syntax (called self-documenting expressions) that does it in one step:

Python· Runs on this page
Practise on the challenge page →
name = 'Sam'
age = 18

print(f'{name=}, {age=}')

Output:

Text
name='Sam', age=18

See? The variable name and the equals sign are added for you, and the string even gets quotes around it. This is super handy for debugging. It has been around since Python 3.8, but lots of people still don't know about it – don't miss out!

You can even put a whole expression in it:

Python· Runs on this page
Practise on the challenge page →
a = 3
b = 4

print(f'{a + b = }')

Output:

Text
a + b = 7

Notice that the spaces around = are kept exactly as you typed them. If you want neat output, just control the spaces yourself.

(2) Format specs: alignment, decimal places, thousands separators

Inside the curly braces of an f-string, you can add a colon : followed by a format spec. It controls how the value looks.

Keep 2 decimal places:

Python· Runs on this page
Practise on the challenge page →
pi = 3.1415926

print(f'{pi:.2f}')

Output:

Text
3.14

Right-align in a space 10 characters wide:

Python· Runs on this page
Practise on the challenge page →
name = 'Sam'

print(f'[{name:>10}]')

Output (the gap is spaces):

Text
[       Sam]

> means right-align, < means left-align, and ^ means centre.

Add commas to big numbers:

Python· Runs on this page
Practise on the challenge page →
amount = 1234567890

print(f'Order total: ${amount:,}')

Output:

Text
Order total: $1,234,567,890

Show as a percentage:

Python· Runs on this page
Practise on the challenge page →
rate = 0.875

print(f'Success rate: {rate:.1%}')

Output:

Text
Success rate: 87.5%

See? Jobs that used to need round, format or joining strings together can all be done with one f-string.

(3) Python 3.12+: quotes inside f-strings are no longer a problem

One last thing: a new feature in Python 3.12 (PEP 701). Before 3.12, f-strings had an annoying rule: if you wrote a string inside the curly braces, its quotes could not be the same as the outer quotes.

For example, the code below is wrong in Python 3.11 and earlier:

Python· Read with the text above
data = {'name': 'Sam', 'age': 18}

# Only allowed in Python 3.12+: single quotes inside and outside
print(f'The nickname is {data['name']}')

Output:

Text
The nickname is Sam

In older versions, this code gives a SyntaxError. You would have to switch the outer quotes to double quotes, or use an extra variable. From 3.12, this rule is gone: you can mix the outer and inner quotes however you like. This is really helpful when you write complex templates.

Python 3.12 also removed other limits: f-strings can now have expressions over several lines, comments, and backslashes. So when you use Python 3.12+, you can write f-strings pretty much any way you want – no more strange rules.

4. String Encoding

We all know computers can only work with numbers. To work with text, the computer must first turn the text into numbers. Early computers used 8 bits as one byte, so the biggest number one byte can hold is 255 (binary 11111111 = decimal 255). The numbers 0 – 255 were used for capital and small English letters, digits and some symbols. This table is called ASCII encoding. For example, capital A is 65, and small z is 122.

To show Chinese, one byte is clearly not enough. You need at least two bytes, and it must not clash with ASCII. So China created the GB2312 encoding for Chinese characters.

Japanese, Korean and other languages had the same problem. To put all the world's writing into one system, Unicode was created. Unicode puts every language into one set of codes, so there are no more garbled characters.

Unicode usually uses two bytes for one character. To turn an old English (ASCII) code into Unicode, you just fill the extra byte with 0.

Python was born before the Unicode standard was published, so the earliest Python only supported ASCII. A normal string like 'ABC' was stored as ASCII inside Python.

Python added Unicode support later. Unicode strings were written as u'...'.

But in modern Python 3, strings are Unicode. This means Python strings support many languages. That's why in the examples above, I didn't need to add u'...' and everything still showed correctly.

However, Python source code is itself a text file. So when your code contains non-English text (for example Chinese), you must save the file in UTF-8 encoding. To make sure the Python interpreter reads the file as UTF-8, we usually put these two lines at the top:

Python· Read with the text above
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

The first comment tells Linux/OS X that this is a Python program that can be run. Windows ignores it.

The second comment tells the Python interpreter to read the source code as UTF-8. Otherwise, non-English text in your code might come out as garbled characters.

Declaring UTF-8 does not mean your .py file really is UTF-8. You must also make sure your text editor is saving with UTF-8 without BOM.

5. Converting Between Basic Data Types

Here are the ways to convert between basic data types in Python.

Function What it does
int(x [,base ]) Turns x into an integer
float(x ) Turns x into a float
complex(real [,imag ]) Makes a complex number
str(x ) Turns object x into a string
repr(x ) Turns object x into an expression string
eval(str ) Works out a valid Python expression inside a string and returns an object
tuple(s ) Turns sequence s into a tuple
list(s ) Turns sequence s into a list
chr(x ) Turns an integer into a character
ord(x ) Turns a character into its integer value
hex(x ) Turns an integer into a hexadecimal string
oct(x ) Turns an integer into an octal string

Note: Python 3 has only one integer type, int, which can hold very big numbers. There is no Long type like in Python 2.

Let's try some of these functions.

For example, the int() function turns a string that looks like a whole number into an integer.

Python· Runs on this page
Practise on the challenge page →
str1 = '100'
str2 = '300'

print(str1 + str2)
print(int(str1) + int(str2))

Output:

Text
100300
400

Notice we said "a string that looks like a whole number". Strings made of words can't be turned into integers by int().

Strings with a decimal point also can't be turned into integers by int().

Python· Read with the text above
print(int('88.88'))

This gives an error:

Text
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    print(int('88.88'))
ValueError: invalid literal for int() with base 10: '88.88'

But this doesn't mean floats can't become integers. It only means a string with a decimal point can't be forced into an integer by int().

A float can still be converted with int().

For example:

Python· Runs on this page
Practise on the challenge page →
print(int(88.88))

Output:

Text
88

But notice the result is 88. The 0.88 after the decimal point is gone.

This is because int() turns data into an integer. When it turns a float into an integer, it just cuts off the decimal part and keeps the whole number part. So the output is 88.

I won't go through every function one by one. Just use them and try them, and you will slowly get to know them. If you are a beginner, play with every one of them! Write anything you like, run it, and look at the result. Don't worry – your computer won't break from this.

6. Variables in Python

1. Creating and Assigning Variables

In a Python program, a variable has a name, and it can hold any type of data. A variable name can only use English letters (capital or small), digits and underscores (_), and it can't start with a digit. For example:

Python· Read with the text above
a=88

Here, a is a variable that holds an integer. Notice that in Python you don't have to say what type of data a variable holds. In Python, = is the assignment statement, just like in other languages. Because you don't need to declare the type, you can give a variable any type of data. You can also change the same variable again and again, even to a different type.

Python· Runs on this page
Practise on the challenge page →
a = 'Hello Python'
print(a)
a = 123
print(a)

Output:

Text
Hello Python
123

A language where a variable's type isn't fixed is called a dynamic language. The opposite is a static language. In a static language, you must give each variable a type when you create it, and if you assign the wrong type, you get an error. Java is a static language, for example.

2. What a Variable Points To

Look at this code. The variable b prints Hello Python at the end.

Python· Runs on this page
Practise on the challenge page →
a = 'Hello Python'
b = a
a = 123
print(b)

Output:

Text
Hello Python

Here's why: at first, variable a points to the string Hello Python. Then b = a creates variable b, and b points to the same string that a points to, Hello Python. Finally, a = 123 makes a point to 123 instead. So when we print b, we still get Hello Python.

You can think of it like this:

  • ① Variable a points to the string 'Hello Python'
  • ② b = a: variable b also points to 'Hello Python'
  • ③ a = 123: variable a now points to the integer 123, but b still points to 'Hello Python'

3. Assigning Several Variables at Once

Python lets you assign values to several variables at the same time. For example:

Python· Read with the text above
a = b = c = 1

In this example, one integer object with the value 1 is created, and all three variables point to the same place in memory.

You can also give several variables different values at once. For example:

Python· Read with the text above
a, b, c = 1, 2, "liangdianshui"

Here, the integers 1 and 2 go to variables a and b, and the string "liangdianshui" goes to variable c.

Guess the output first, then explain what the variables point to

We've covered assigning variables. Now, don't run it yet. Guess what the last two lines print:

Python· Runs on this page
Practise on the challenge page →
minutes = 15
recorded = minutes
minutes = minutes + 5
print(minutes)
print(recorded)

Output:

Text
20
15

recorded = minutes makes both names point to the same integer object at first. But it does not make them "change together forever". minutes = minutes + 5 works out a new result and points minutes to it. recorded still points to the old integer.

Now change the starting value to 0 and work it out yourself. You should get 5 and 0. If your guess was wrong, look back at "What a Variable Points To" and check, after each assignment, where each name is pointing.

One more thing that's easy to mix up: '15' is text, and 15 is an integer. When you need to do maths, convert it as needed. Just because they look the same on screen doesn't mean they work the same way. Try int('15') + 5, then try '15' + '5', and explain why you get 20 and '155'.

When you're starting out, name your variables with English letters, digits and underscores. Python actually allows some non-ASCII characters in names too, as long as they follow the rules for identifiers – it's not limited to English letters. But while learning, keep using clear English names, and remember that keywords (like if or for) can't be used as normal variable names.
