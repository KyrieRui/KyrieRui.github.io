Introduction

People often say computers are amazing and super smart. Actually, computers aren't smart at all. Just trying to talk to one can drive you crazy! The smart one is you, the person writing the program.

Writing a program means talking to the computer and telling it what to do.

So of course, we need some logic when we talk to it. For example, you need to tell the computer what to do in which situation, or what to do at what time.

All of this needs logical decisions. That's what this chapter is about.

1. Conditional Statements

1. What is a Conditional Statement?

Conditional statements in Python work basically the same as in other languages. The result of one or more checks (True or False) decides which block of code runs.

In Python, any value that is not 0 and not empty counts as True. 0 or empty (null) counts as False.

Here is the flow chart:

2. The Basic Form of an if Statement

In Python, the basic form of an if statement looks like this:

Python· Syntax only
if condition:
    do something……
else:
    do something else……

As we said in earlier chapters, Python is very strict about indentation, so be careful with it here. And don't forget the colon :.

In the condition of an if statement, you can use > (greater than), < (less than), == (equal to), >= (greater than or equal to) and <= (less than or equal to) to compare things.

For example:

Python· Runs on this page
Practise on the challenge page →
# -*-coding:utf-8-*-

results=59

if results>=60:
    print ('Pass')
else :
    print ('Fail')

Output:

Text
Fail

As we said above, non-zero numbers, non-empty strings, non-empty lists and so on count as True. Everything else is False. So you can also write:

Python· Runs on this page
Practise on the challenge page →
num = 6
if num :
    print('Hello Python')

Output:

Text
Hello Python

So the message was printed.

What if we change num to an empty string?

Python· Read with the text above
num = ''
if num :
    print('Hello Python')

Nothing is printed (the program ends normally, without printing Hello Python).

Clearly, an empty string is False. It doesn't meet the condition, so print('Hello Python') never runs.

One more reminder: after the colon : in a condition, the next line must be indented. If it's not indented, you get an error.

Python· Read with the text above
num = ''
if num :
print('Hello Python')

Running it gives an error:

Text
  File "/Users/twowater/dev/python/test/com/twowater/test.py", line 4
    print('Hello Python')
        ^
IndentationError: expected an indented block

The colon and indentation are part of the syntax. They help Python see which code belongs where, and understand the logic and order of what runs.

3. if with Several Conditions in Turn

Sometimes we need more than two choices. In the example above, 60 or more is a pass. What if we also want 90+ to be "Excellent", and 80 – 90 to be "Good"?

Then we use an if statement with several conditions.

In pseudocode (plain-language code):

Python· Syntax only
if condition1:
    do thing 1……
elif condition2:
    do thing 2……
elif condition3:
    do thing 3……
else:
    do thing 4……

Example:

Python· Runs on this page
Practise on the challenge page →
# -*-coding:utf-8-*-

results = 89

if results > 90:
    print('Excellent')
elif results > 80:
    print('Good')
elif results > 60:
    print ('Pass')
else :
    print ('Fail')

Output:

Text
Good

4. if Checking Several Conditions at Once

What do we do when there are several conditions at the same time?

For example, a student is "Excellent" only if both their Java and Python test scores are over 80. How do we do that?

We can use or and and.

or means the check succeeds if at least one of the two conditions is true.

and means the check succeeds only if both conditions are true.

For example:

Python· Runs on this page
Practise on the challenge page →
# -*-coding:utf-8-*-

java = 86
python = 68

if java > 80 and  python > 80:
    print('Excellent')
else :
    print('Not excellent')

if ( java >= 80  and java < 90 )  or ( python >= 80 and python < 90):
    print('Good')

Output:

Text
Not excellent
Good

Note: when an if has several conditions, you can use brackets to show which to check first. Checks inside brackets happen first. Also, and and or have lower priority than >, < and other comparison symbols. So without brackets, greater-than and less-than are checked before and/or.

5. Nested if

What is a nested if?

It's just what it sounds like: an if statement inside another if statement.

The example above can also be written with a nested if:

Python· Runs on this page
Practise on the challenge page →
java = 86
python = 68

if java > 80:
    if python > 80:
        print('Excellent')
    else:
        print('Not excellent')
else:
    print('Not excellent')

Output:

Text
Not excellent

Of course, this is just to show that if statements can be nested. For this task, I don't really recommend nesting like this. It makes the code longer, and too much nesting makes code hard to read.

6. New in Python 3.10+: match / case

Hey everyone! If you're using Python 3.10 or newer, there's another, clearer tool besides if / elif / else: match / case. It's called structural pattern matching.

Why talk about it specially?

Let's look at a task first. Say Brother Shui wants to do different things depending on a command string from the server:

Python· Runs on this page
Practise on the challenge page →
command = 'start'

if command == 'start':
    print('Starting')
elif command == 'stop':
    print('Stopping')
elif command == 'pause':
    print('Pausing')
else:
    print('Unknown command')

Output:

Text
Starting

Nothing wrong with this. But when there are lots of choices, a long chain of elif gets wordy. Let's rewrite it with match / case:

Python· Runs on this page
Practise on the challenge page →
command = 'start'

match command:
    case 'start':
        print('Starting')
    case 'stop':
        print('Stopping')
    case 'pause':
        print('Pausing')
    case _:
        print('Unknown command')

Output:

Text
Starting

case _ is the "catch-all" branch, like else. The underscore _ is a wildcard. It matches anything that none of the earlier cases matched.

If you like to think, you might ask: isn't this just switch / case from other languages, with different syntax?

Not quite! The real power of match / case is that it can match structure, not just values.

Here's an example matching a sequence. Say the product team sends us a coordinate:

Python· Runs on this page
Practise on the challenge page →
point = [10, 20]

match point:
    case [0, 0]:
        print('Origin')
    case [x, 0]:
        print(f'On the x-axis, x = {x}')
    case [0, y]:
        print(f'On the y-axis, y = {y}')
    case [x, y]:
        print(f'Normal point, x = {x}, y = {y}')
    case _:
        print('Not a 2D coordinate')

Output:

Text
Normal point, x = 10, y = 20

See? It didn't just match "this is a list of length 2" – it also unpacked x and y for you, ready to use in that branch.

In a sequence, you can also use *rest to collect the remaining elements:

Python· Runs on this page
Practise on the challenge page →
nums = [1, 2, 3, 4, 5]

match nums:
    case [first, *rest]:
        print(f'First: {first}, the rest: {rest}')

Output:

Text
First: 1, the rest: [2, 3, 4, 5]

What about dictionaries?

match / case can also match the shape of a dictionary:

Python· Runs on this page
Practise on the challenge page →
response = {'status': 'ok', 'data': [1, 2, 3]}

match response:
    case {'status': 'ok', 'data': data}:
        print(f'Success, got data {data}')
    case {'status': 'error', 'message': msg}:
        print(f'Failed: {msg}')
    case _:
        print('Unknown response')

Output:

Text
Success, got data [1, 2, 3]

Even cooler, match / case works with classes too. It's even better with dataclass:

Python· Runs on this page
Practise on the challenge page →
from dataclasses import dataclass


@dataclass
class Point:
    x: int
    y: int


p = Point(0, 5)

match p:
    case Point(x=0, y=0):
        print('Origin')
    case Point(x=0, y=y):
        print(f'On the y-axis, y = {y}')
    case Point(x=x, y=0):
        print(f'On the x-axis, x = {x}')
    case Point(x=x, y=y):
        print(f'Normal point ({x}, {y})')

Output:

Text
On the y-axis, y = 5

Finally, one small feature called a guard: you add an if after the case:

Python· Runs on this page
Practise on the challenge page →
score = 75

match score:
    case x if x >= 90:
        print('Excellent')
    case x if x >= 80:
        print('Good')
    case x if x >= 60:
        print('Pass')
    case _:
        print('Fail')

Output:

Text
Pass

See how match / case makes code more structured and easier to read?

One more note: match / case is not meant to replace if / elif. For simple value comparisons and true/false checks, a plain if is actually clearer. match / case really shines when you choose what to do based on the structure of data – for example, reading JSON, working with syntax trees, or writing an interpreter.

2. Loops

1. What is a Loop?

Almost every programming language has loops. Why?

Ask yourself: why do we write programs?

To make our work easier and help us work more efficiently, of course!

Computers are different from humans. Computers don't get tired, don't complain, and don't need a rest. They can keep going forever.

And remember: what computers are best at is doing the same thing again and again.

That's why we need loops. A loop lets us run a statement, or a group of statements, many times.

Here's the general shape of a loop:

Python has for loops and while loops.

Now here's another question: what if I want the loop to stop after 100 times? How do I do that?

We use some loop control statements:

Loop control statement What it does
break Stops the loop while it's running, and jumps out of the whole loop
continue Stops the current round of the loop, skips the rest of it, and goes to the next round
pass pass is an empty statement. It's there to keep the program's structure complete

These control statements let us tell the program when to stop, and when to skip this round.

2. The for Loop

Let's look at the for loop first.

Its flow chart looks like this:

The basic syntax:

Python· Read with the text above
for iterating_var in sequence:
   statements(s)

Using this basic syntax, let's write a quick test:

Python· Read with the text above
for letter in 'Hello Shui':
    print(letter)

Output:

Text
H
e
l
l
o
 
S
h
u
i

From the output, we can see it prints the string Hello Shui one character at a time.

What if we use a dictionary instead of a string?

Python· Runs on this page
Practise on the challenge page →
dict = {'One Drop': 'Primary student', 'Two Drops': 'Middle school student', 'Three Drops': 'High school student'}

for i in dict:
    print(i)

Output:

Text
One Drop
Two Drops
Three Drops

You'll see it only prints each key in the dictionary.

I often tell everyone: whenever you learn something new, try it out lots of ways.

A conclusion you find yourself by trying once is better than hearing someone else say it ten times.

Don't know what to try?

Use our examples to think of new ones. For the for loop above, we tried a string and a dictionary. What other basic data types have we learned?

If you don't remember, go back and look. Try all the basic types.

For example, if you try, you'll find that integers and floats can't be put directly into a for loop:

a = 100

b = 0.01

3. The range() Function

for loops are often used together with the range() function.

If you don't know range(), let's understand it with some code:

Python· Runs on this page
Practise on the challenge page →
for i in range(3):
    print(i)

Output:

Text
0
1
2

So it prints 0 up to (but not including) 3.

range(x) makes a sequence of whole numbers from 0 to x-1.

range(a,b) makes a sequence of whole numbers that includes a but not b.

In fact, range(3) in the example can be written as range(0,3) – the result is the same.

Most of the time, we use range() to run some code n times.

Here's a question: look closely at range(). Whether it has 1 argument or 2, what do they have in common?

Did you notice? They always go up by 1 each time.

range(3) is 0, 1, 2 – going up by 1 each time.

range(3,6) is 3, 4, 5 – also going up by 1 each time.

Can we go up by something other than 1?

What if I want to go up by 2?

When you write programs, you'll definitely need this. And of course Python's range can do it.

So range can also take three arguments.

For example, range(0,10,2) means: count from 0 to 10 (not including 10), going up by 2 each time.

Python· Runs on this page
Practise on the challenge page →
for i in range(0, 10, 2):
    print(i)

Output:

Text
0
2
4
6
8

4. The while Loop

A while loop does the same job as a for loop.

Let's see what a while loop looks like:

Python· Runs on this page
Practise on the challenge page →
count = 1
sum1 = 0

while count <= 100:    # The condition
    sum1 = sum1 + count    # The body of the while loop
    count = count + 1

print(sum1)

Output:

Text
5050

This example adds up all the whole numbers from 1 to 100.

5. The Difference Between for and while Loops

As we said before, if one piece of syntax can do a job, there's no need for two.

Since both are loops, for and while must be different in some way.

So when should you use a for loop, and when a while loop?

  • A for loop is mainly for going through an iterable (something you can loop over).

  • A while loop is mainly for repeating something as long as a condition is true. (For example, an endless loop that exits with break.)

  • In some cases, for and while can be swapped.

For example:

Python· Runs on this page
Practise on the challenge page →
for i in range(0, 10):
    print(i)


i = 0
while i < 10:
    print(i)
    i = i + 1

The output is the same, but if you think carefully, you'll see they run in a different way and need different information.

6. Nested Loops

Like conditional statements, loops can be nested.

Here's the syntax:

Nested for loop syntax

Python· Read with the text above
for iterating_var in sequence:
   for iterating_var in sequence:
      statements(s)
   statements(s)

Nested while loop syntax

Python· Syntax only
while expression:
   while expression:
      statement(s)
   statement(s)

You can also put a different kind of loop inside: a for loop inside a while loop, or a while loop inside a for loop.

For example:

If we want to stop adding once sum is over 1000, we can use break to exit the whole loop.

Python· Runs on this page
Practise on the challenge page →
count = 1
sum = 0
while (count <= 100):
    sum = sum + count
    if ( sum > 1000):  # Exit the loop when sum is over 1000
        break
    count = count + 1
print(sum)

Output:

Text
1035

Sometimes we only want to add up the odd numbers between 1 and 100. That means when count is even, we want to skip this round and not add it. We can use continue for this:

Python· Runs on this page
Practise on the challenge page →
count = 1
sum = 0
while (count <= 100):
    if ( count % 2 == 0):  # Skip even numbers
        count = count + 1
        continue
    sum = sum + count
    count = count + 1
print(sum)

Output:

Text
2500

And another one:

Python· Runs on this page
Practise on the challenge page →
for num in range(10,20):  # Go through the numbers from 10 to 20
   for i in range(2,num): # Go through possible factors
      if num%i == 0:      # Found the first factor
         j=num/i          # Work out the second factor
         print (f'{num} is a composite number')
         break            # Jump out of the current loop
   else:                  # The else part of the loop
      print (f'{num} is a prime number')

Output:

Text
10 is a composite number
11 is a prime number
12 is a composite number
13 is a prime number
14 is a composite number
15 is a composite number
16 is a composite number
17 is a prime number
18 is a composite number
19 is a prime number

This example also uses a for … else statement.

The statements in the for loop work as normal. The statements in else run only if the loop finishes normally – that is, if the for loop was not stopped by break.

And just like for … else, there is also while … else. They mean the same thing.

1. Print the Times Tables

Python· Read with the text above
# -*- coding: UTF-8 -*-

# Print the 1–9 times tables
for i in range(1, 10):
        for j in range(1, i+1):
            # f-string: put f before the string, and any expression inside {} is worked out and put into the string
            print(f'{i}x{j}={i*j}\t', end='')
        print()

6x1=6   6x2=12  6x3=18  6x4=24  6x5=30  6x6=36  
7x1=7   7x2=14  7x3=21  7x4=28  7x5=35  7x6=42  7x7=49

2. Check for a Leap Year

Python· Run it on your own computer

# Check whether a year is a leap year

year = int(input("Enter a year: "))
if (year % 4) == 0 and (year % 100) != 0 or (year % 400) == 0:
    print(f'{year} is a leap year')
else:
     print(f'{year} is not a leap year')

First, write down how you'd count by hand

We're going to add up study time. The records might include 0, and might include negative numbers typed by mistake. Let's agree on a rule first: zero minutes is allowed and kept, but negative numbers are skipped for now. How would you do this by hand? Start from zero, look at each record one by one, and only add the ones that follow the rule.

Python· Runs on this page
Practise on the challenge page →
records = [15, 0, 10, -3]
total = 0
valid_count = 0
for minutes in records:
    if minutes < 0:
        continue
    total = total + minutes
    valid_count = valid_count + 1
print(total)
print(valid_count)

Output:

Text
25
3

Don't just look at the total. Follow the loop step by step and write down minutes, total and valid_count each time. Zero minutes doesn't add to the total, but it's still a valid record, so the count of valid records is 3.

Try two edge cases yourself: an empty list should give 0 and 0. A list of only negative numbers should too. If you change the check to minutes <= 0, the total might stay the same, but the count changes. This shows that one correct number in the output doesn't mean the whole program does what it should.

Skipping negative numbers is just the rule for this exercise. Not every program should quietly skip mistakes. When we learn about exception handling, we'll change it to tell the caller what was wrong.
