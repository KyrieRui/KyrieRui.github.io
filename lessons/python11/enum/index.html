1. Using Enum Classes

In real projects, we always need to define constants. One way to define constants is to use capitalised variable names with integers – for example, months:

Python· Read with the text above
JAN = 1
FEB = 2
MAR = 3
...
NOV = 11
DEC = 12

This is quick and simple, but the type is just int, and they're still variables (they could be changed).

Is there a better way?

We can define a class, where each constant is a unique instance inside the class.

Python has an Enum class (short for enumeration) that does exactly this:

Python· Read with the text above
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

from enum import Enum

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'))

# Loop through the enum
for name, member in Month.__members__.items():
    print(name, '---------', member, '----------', member.value)

# Use one constant directly
print('\n', Month.Jan)

Output:

Text
Jan --------- Month.Jan --------- 1
Feb --------- Month.Feb --------- 2
Mar --------- Month.Mar --------- 3
Apr --------- Month.Apr --------- 4
May --------- Month.May --------- 5
Jun --------- Month.Jun --------- 6
Jul --------- Month.Jul --------- 7
Aug --------- Month.Aug --------- 8
Sep --------- Month.Sep --------- 9
Oct --------- Month.Oct --------- 10
Nov --------- Month.Nov --------- 11
Dec --------- Month.Dec --------- 12

 Month.Jan

We used Enum to define an enum class.

In the code above, we created an enum type for months called Month. Look at the arguments: the first one, Month, is the name of the enum class. The second, a tuple, gives the enum's members. And we use __members__ to loop through all its members.

Note: member.value is an int constant given to each member automatically, starting from 1 by default.

Also, every Enum member is a singleton (there's only ever one of it). Members can't be instantiated and can't be changed.

A status's name and a status's value

We want to label study tasks as "To do" or "Done". Let's use an enum to list the allowed statuses clearly, and look at the member's name and value separately:

Python· Runs on this page
from enum import Enum


class StudyState(Enum):
    TODO = 'To do'
    DONE = 'Done'


print(StudyState.TODO.name)
print(StudyState.TODO.value)
print(StudyState('Done') is StudyState.DONE)

Output:

Text
TODO
To do
True

TODO is the member's name, and 'To do' is the value we gave it. StudyState('Done') finds the member by its value – it doesn't create a new status with any content you like.

Try a value that was never defined and look at the ValueError. Then compare StudyState.TODO == 'To do'. The result is False, because a normal Enum member here is not the same thing as its string value. Comparison rules for other kinds of enums depend on their type – don't assume from this one example that all enums work like strings.

The source code analysis in this chapter can help you understand how it's built. But after you've finished a small task like choosing a status, coming back to it usually makes it easier to know which part of the logic you're following.

2. The Source Code of Enum

From the example above, we know __members__ lets us loop through all the members of an enum class.

But have you wondered why?

When you saw that code, did you wonder how __members__ is able to list all the members of an enum?

Let's take a rough look at how Enum is built in its source code.

Enum lives in the module enum.py. First, here's a piece of the Enum class:

Python· Read with the text above
class Enum(metaclass=EnumMeta):
    """Generic enumeration.
    Derive from this class to define new enumerations.
    """

You can see Enum uses the metaclass EnumMeta. Now here's the relevant piece of EnumMeta:

Python· Read with the text above
class EnumMeta(type):
    """Metaclass for Enum"""
    @property
    def __members__(cls):
        """Returns a mapping of member name->value.
        This mapping lists all enum members, including aliases. Note that this
        is a read-only view of the internal mapping.
        """
        return MappingProxyType(cls._member_map_)

First, the __members__ method returns a MappingProxyType that wraps a dict (a map). And @property changes how __members__(cls) is used, so it's accessed like a variable instead of a method. That's why we can just write __members__ to access it.

        3. Custom types, @unique, auto()
        

        1. Values can be any type
        

        An Enum member's value doesn't have to be a number – strings, tuples and objects all work:
        

        Python· Runs on this page
        from enum import Enum

class Month(Enum):
    Jan = 'January'
    Feb = 'February'
    Mar = 'March'
    # ...
    Dec = 'December'

print(Month.Jan)         # Month.Jan
print(Month.Jan.name)    # 'Jan'
print(Month.Jan.value)   # 'January'
        

        2. @unique: no repeated values
        

        By default, an Enum allows several members to have the same value – the later one becomes another name (an alias) for the earlier one.
        

        Python· Runs on this page
        from enum import Enum

class Color(Enum):
    RED = 1
    SCARLET = 1   # no error – SCARLET becomes another name for RED

print(Color.SCARLET is Color.RED)   # True
        

        If you don't want that, add the @unique decorator. It forces every value to be unique and raises an error straight away if one repeats:
        

        Python· Read with the text above
        from enum import Enum, unique

@unique
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3
    # SCARLET = 1   ← adding this line gives a ValueError
        

        3. auto(): let Python choose the values
        

        Lots of members, and you don't care what the actual values are? Use auto() to let Python assign them:
        

        Python· Runs on this page
        from enum import Enum, auto

class Weekday(Enum):
    MON = auto()
    TUE = auto()
    WED = auto()
    THU = auto()
    FRI = auto()
    SAT = auto()
    SUN = auto()

print(Weekday.MON.value)   # 1
print(Weekday.SUN.value)   # 7
        

        auto() starts at 1 and counts up by default. To change the starting value or the step, you can override the _generate_next_value_ method (an advanced trick – skip it for now).
        

        4. IntEnum / StrEnum
        

        If you want Enum members to also be ints (so they can do arithmetic and be compared with ints), use IntEnum:
        

        Python· Runs on this page
        from enum import IntEnum

class Priority(IntEnum):
    LOW = 1
    MID = 5
    HIGH = 10

print(Priority.LOW < Priority.HIGH)   # True
print(Priority.MID + 1)               # 6
        

        StrEnum (Python 3.11+) is the same idea for strings.

          3. Enums with Custom Values
          

          Sometimes we need to control the values in an enum. We can make our own class that inherits from Enum. Let's change the example above:
          

          Python· Read with the text above
          #!/usr/bin/env python3
# -*- coding: UTF-8 -*-
from enum import Enum, unique

Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'))


# The @unique decorator checks that there are no repeated values
@unique
class Month(Enum):
    Jan = 'January'
    Feb = 'February'
    Mar = 'March'
    Apr = 'April'
    May = 'May'
    Jun = 'June'
    Jul = 'July'
    Aug = 'August'
    Sep = 'September '
    Oct = 'October'
    Nov = 'November'
    Dec = 'December'


if __name__ == '__main__':
    print(Month.Jan, '----------',
          Month.Jan.name, '----------', Month.Jan.value)
    for name, member in Month.__members__.items():
        print(name, '----------', member, '----------', member.value)
          

          Output:
          

          Text
          Month.Jan ---------- Jan ---------- January
Jan ---------- Month.Jan ---------- January
Feb ---------- Month.Feb ---------- February
Mar ---------- Month.Mar ---------- March
Apr ---------- Month.Apr ---------- April
May ---------- Month.May ---------- May
Jun ---------- Month.Jun ---------- June
Jul ---------- Month.Jul ---------- July
Aug ---------- Month.Aug ---------- August
Sep ---------- Month.Sep ---------- September
Oct ---------- Month.Oct ---------- October
Nov ---------- Month.Nov ---------- November
Dec ---------- Month.Dec ---------- December
          

          From this example, we can see the enum module gives us enum types that can be iterated and compared. It lets you create clearly defined names for values, instead of using bare integers or strings.

          4. Comparing Enums
          

          Enum members have no order, so they can only be compared by identity (is) and equality (==). Let's see how == and is work:
          

          Python· Read with the text above
          
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-
from enum import Enum


class User(Enum):
    Twowater = 98
    Liangdianshui = 30
    Tom = 12


Twowater = User.Twowater
Liangdianshui = User.Liangdianshui

print(Twowater == Liangdianshui, Twowater == User.Twowater)
print(Twowater is Liangdianshui, Twowater is User.Twowater)

try:
    print('\n'.join('  ' + s.name for s in sorted(User)))
except TypeError as err:
    print(f' Error : {err}')
          

          Output:
          

          Text
          
False True
False True
 Error : '<' not supported between instances of 'User' and 'User'
          

          Look at the last line of output: there's an error. That's because the greater-than and less-than operators raise a TypeError. In other words, members of an Enum class can't be compared with < or >.
          

          So can we make enum members comparable by size?
          

          Of course! Use the IntEnum class, and comparisons work.
          

          Python· Runs on this page
          #!/usr/bin/env python3
# -*- coding: UTF-8 -*-
import enum


class User(enum.IntEnum):
    Twowater = 98
    Liangdianshui = 30
    Tom = 12


try:
    print('\n'.join(s.name for s in sorted(User)))
except TypeError as err:
    print(f' Error : {err}')
          

          Look at the output:
          

          Text
          Tom
Liangdianshui
Twowater
          

          You can see the enum members are sorted by the size of their values. So they can be compared by size.
