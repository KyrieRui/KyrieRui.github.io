1. What is Python?

Python was created by Guido van Rossum (his fans call him "Uncle Turtle" in Chinese). He wrote it over Christmas 1989, just because he was bored during the holidays. Some people are simply amazing – he made a super powerful programming language just to pass the time!

Today there are about 600 programming languages in the world, but only about 20 are really popular. Have you heard of the TIOBE ranking?

And here is how the TIOBE index changed for the Top 10 languages:

The TIOBE Programming Community Index (source: www.tiobe.com) from 2002 to 2017 shows: Java stayed high at 15% – 25% for years, taking turns in first place with C. C slowly went down overall. C++ fell from 15% to about 5%. Python, PHP, JavaScript, C# and others went up and down between 2% and 10%. Perl, Visual Basic .NET and Delphi/Object Pascal slowly faded away.

Overall, each of these languages has its own strengths. But it's easy to see that Python has grown very fast in recent years – especially because of machine learning and data analysis, which are very popular now.

Python is a high-level programming language, and one of its big strengths is that you can build things quickly. Python comes with a very complete standard library. It covers networking, files, GUIs (windows and buttons), databases, text and lots more. People say Python comes with "batteries included". With Python, you don't need to write lots of features from scratch – you can use ready-made ones. You can also build websites with Python. Many big websites were built with it, like YouTube, Instagram, and Douban in China. Many big companies, like Google and Yahoo, and even NASA, use Python a lot.

Of course, every language has good points and bad points, and Python is no different. So what are Python's weak points?

The first is that it runs slowly – very slowly compared to C. Python is an interpreted language. When your code runs, it is translated, line by line, into machine code that the CPU understands. This translation takes a lot of time, so it's slow. A C program is compiled into machine code before it runs, so it's very fast.

The second is that your code can't be hidden. If you share your Python program, you are really sharing your source code. Compiled languages like Java and C don't have this problem, but interpreted languages must share their source code.

2. Installing Python

The screenshots and commands below use Python 3.6 / 3.7 as an example. The installer you see today may look different. For the exercises, download a Python 3 version that is still supported from the official Python download page, and check the minimum version each chapter asks for. After installing, run python3 --version (on Windows you can also use py --version) to check which version is really running. Use your own install location for any paths.

Python is cross-platform. It runs on Windows, Mac and all kinds of Linux/Unix systems. Python has had two main versions: 2.x and 3.x. They do not work with each other. I installed version 3.6.1.

Where should you download it? I suggest the official website, so you always get the newest version. The official website is: https://www.python.org/

1. Installing on Windows

On Windows, after downloading, just run the installer. Remember to tick Add Python 3.6 to PATH, then click Install Now to finish.

Pay attention here: make sure you tick "Add Python 3.6 to Path". If you tick it, you don't need to set up the environment variable yourself. If you don't, you will have to do it by hand.

In the "Install Python 3.6.1 (64-bit)" setup window, you will see two choices:

  • Install Now: install with the default settings. The default path is C:\Users\Administrator\AppData\Local\Programs\Python\Python36. It includes IDLE, pip and the documentation, and creates shortcuts and file links.
  • Customize installation: choose your own install path and features.

Whichever you choose, there are two tick boxes at the bottom: "Install launcher for all users (recommended)" and "Add Python 3.6 to PATH". Tick the second one and you won't need to set up the environment variable yourself. Don't forget this step!

If you clicked too fast and forgot to tick "Add Python 3.6 to Path", don't worry. You just need to set the environment variable by hand.

In the command prompt (cmd), type:

Text
path=%path%;C:\Python

Very important: C:\Python is the folder where Python is installed. If you installed it somewhere else, type your own folder instead.

After installing, open a command prompt window and type python. If you see something like this, Python is installed:

Text
C:\Users\Administrator>python
Python 3.6.1 (v3.6.1:69c0db5, Mar 21 2017, 18:41:36) [MSC v.1900 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>

When you see the >>> prompt, you are in Python's interactive mode. You can type any Python code, press Enter, and see the result right away.

2. Installing on Mac

Macs often came with Python 2.x already installed, but nobody uses 2.x now. So I suggest downloading the newest version from https://www.python.org/downloads/mac-osx/ and installing it.

After installing, how do you set the environment variable?

First, check the current PATH:

Text
echo $PATH

Then open ~/.bash_profile (create it if it doesn't exist)

Text
vi ~/.bash_profile

I installed Python 3.7, so the Python path is /Library/Frameworks/Python. Framework/Versions/3.7/bin. So I add this line:

Text
export PATH="/Library/Frameworks/Python. Framework/Versions/3.7/bin:$PATH"

After that, ~/.bash_profile looks roughly like this (this is from my own computer):

Bash
# Setting PATH for Python 3.6
# The original version is saved in .bash_profile.pysave
PATH="/Library/Frameworks/Python.framework/Versions/3.7/bin:${PATH}"
export PATH

Finally, save and quit, then load the file:

Text
source ~/.bash_profile

3. Your First Python Program

OK, enough talking. Now we can write our first Python program!

When you start writing Python, I don't really suggest using a special tool, because it makes it harder to get used to the syntax. So here I will use Sublime Text. Later you can switch to PyCharm.

Our first Python program will, of course, print Hello Python.

If you have never programmed before and don't understand anything yet, that's OK. For your first program, just follow along, get a feel for it, and give it a try.

Create a new file and name it HelloPython.py. Notice that the file ends with .py.

Then open the file and type print('Hello Python')

print('Hello Python')

Finally, open a command line window, go to the folder where HelloPython.py is, and you can run the program. Here is the result:

Text
C:\Users\Administrator>cd C:\Users\Administrator\Desktop\Python

C:\Users\Administrator\Desktop\Python>python HelloPython.py
Hello Python

C:\Users\Administrator\Desktop\Python>

If you use Sublime Text, and you set up the environment variable when you installed Python, you can just press Ctrl + B to run it. The result looks like this:

Note: in the bottom-right corner of Sublime Text, choose Python as the syntax. Otherwise Ctrl + B won't run your code correctly. After running, you will see the result in the output panel at the bottom:

Text
Hello Python
[Finished in 0.5s]

Once your first line works, change one small thing

The program above can already print text. First, write down two lines you would like to see. Then change the text below to your own version:

Python· Runs on this page
Practise on the challenge page →
print('Today I start learning Python')
print('First, finish a small example that runs')

Output:

Text
Today I start learning Python
First, finish a small example that runs

This time, only change the text inside the quotes. Run it and check that you get two lines. Next, leave out a closing bracket on purpose and run it again. Look at the error. When you read an error, first find the error type and where in the code it is. Don't delete everything and start again straight away. Put the bracket back, run it again, and check the problem is gone. This is a small but complete cycle: change, observe, fix.

The quotes and brackets here are Python syntax, so they must be normal keyboard symbols (not fancy "curly" quotes). Inside the quotes is the text we want to show, and it can be in any language. Special punctuation in the output text won't cause a syntax error.

Running code in the browser lets us focus on the code first. When you need to work with local files or the command line, set up Python by following the installation chapter. For now, just pick one editor that can run programs. You don't need to install every editor just to write your first line of code.

4. Integrated Development Environment (IDE): PyCharm

While you are learning, I suggest writing Python in a plain text editor, or a tool like Sublime Text. This helps you understand the whole process.

Of course, if you already know some programming, you can use an IDE (Integrated Development Environment) to work faster. A good choice is PyCharm. PyCharm is a Python IDE made by JetBrains. It works on macOS, Windows and Linux.

Download PyCharm here: https://www.jetbrains.com/pycharm/download/
