# 尸潮幸存者 · 中文版

基于 https://github.com/tomerab1/vampire-survivor ，上游基线 9c9db5ce3c120ec4e2c1d6e295fabd98ec0bcd8c。
中文化版本新增暂停、英雄属性、武器详情和被动加成面板。

进入游戏后，按 Esc / P 或右下角按钮暂停，左右方向键切换属性页。
WASD 移动、空格闪现、回车开始；数字键选择角色或升级。

此目录是静态 WebAssembly 构建，使用本地尸潮 AI，无需服务器密钥。
上游 Cargo.toml 声明代码为 MIT。角色/场景来自 0x72 DungeonTileset II；音效来自 TomMusic、Kenney；中文字体为 Noto Sans CJK SC。随资源保留相关许可文件。
