# Python for Beginners

> The IT industry changes and grows faster than most traditional industries. If you stop learning, you'll soon be left behind. But remember: the people left behind are always the ones who stay at beginner level – people with really solid skills are always in demand. So when it comes to learning, we need to be steady and careful.
>
> Teaching yourself Python is the same. Don't get over-excited at the start and keep bookmarking websites, buying lots of books and downloading piles of video lessons. A few days later, your excitement fades. A few weeks later, you've finally completed the course "From Getting Started to Giving Up". So, learning Python takes one step at a time, steadily and carefully.

## About this English edition

This is a simple-English translation of the Chinese tutorial by walter201230 ([github.com/walter201230/Python](https://github.com/walter201230/Python)), shared under the CC BY 4.0 licence. The tutorial is written for Python 3.10+, and some chapters point out new features from 3.11/3.12/3.13.

The original author's interactive site, [learn-py.org](https://learn-py.org), lets you write code in the browser with automatic marking (in Chinese).
