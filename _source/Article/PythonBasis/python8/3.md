# 3. Class Methods #


## 1. How a Class Method Uses Class Attributes ##

We now know how to define a class. Here we'll see how a class method uses the class attributes in the same class.

Let's go straight to an example:


```python
class ClassA():
    var1 = 'Two Drops'

    @classmethod
    def fun1(cls):
        print('I am fun1 ' + cls.var1)


ClassA.fun1()
```

Output:

```
I am fun1 Two Drops
```

Notice there's an extra `@classmethod` above the method. What's that for?

It says the function below it is a **class method**. The name makes it easy to understand:

"class" is class, and "method" is method.

Do we really have to write this?

Yes, we do.

If you leave it out, you'll get an error.

If you don't declare it as a class method, `cls` isn't passed in, and you can't use `cls` to get the class attributes.

So for a class method to use class attributes, you need to:

* Put `@classmethod` above the method to declare it as a class method. Only then can it use class attributes.
* Write `cls` as the first parameter. `cls` is short for "class". It means the class itself is passed in as an argument, so the method can use the class attributes.
* Use class attributes like this: `cls.variable_name`


Remember: you can't leave out `@classmethod` **or** `cls`.

Leave either one out and you'll get an error.





## 2. Passing Arguments to Class Methods ##

We've learned how a class method uses class attributes. How do we pass arguments to a class method?

It's simple – just like a normal function, add more parameters.

Here's an example:

```python
class ClassA():
    var1 = 'Two Drops'

    @classmethod
    def fun1(cls, age):  # Added an age parameter
        print('I am fun1 ' + cls.var1)
        print('Age: ' + str(age))


ClassA.fun1(18)  # Passing an extra argument
```

Output:

```
I am fun1 Two Drops
Age: 18
```
