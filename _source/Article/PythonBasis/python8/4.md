# 4. Changing and Adding Class Attributes #


## 1. Adding and Changing Class Attributes from Inside ##

Let's review the structure of a class:

![The structure of a class](../../images/diagrams/class-structure.svg)

Looking at this, here's a question: how do we change a class attribute – a variable inside the class?

From the structure, we can guess: through a class method. That is, change and add class attributes from **inside** the class.

Here's an example:

<!-- skip-ci -->
```python
class ClassA():
    var1 = 'Two Drops'

    @classmethod
    def fun1(cls):
        print('The old value of var1 is: ' + cls.var1)
        cls.var1 = input('Enter a new value for var1: ')
        print('var1 is now: ' + cls.var1)
        cls.var2 = input('New class attribute var2 – give it a value: ')
        print('var2 is now: ' + cls.var2)


ClassA.fun1()
```

Output (the values after the colons are what I typed):

```
The old value of var1 is: Two Drops
Enter a new value for var1: Three Drops
var1 is now: Three Drops
New class attribute var2 – give it a value: Four Drops
var2 is now: Four Drops
```

I'll say it again: write the examples yourself. Don't just read them. Run them, see what happens, and think.




## 2. Adding and Changing Class Attributes from Outside ##

We've just seen how to change class attributes with a class method. Now let's see how to change and add class attributes from **outside**.

Example:

<!-- skip-ci -->
```python
class ClassA():
    var1 = 'Two Drops'

    @classmethod
    def fun1(cls):
        print('var1 is: ' + cls.var1)


ClassA.fun1()
ClassA.var1 = input('Enter a new value for var1: ')
ClassA.fun1()

ClassA.var2 = input('Enter a value for the new attribute var2: ')
print(ClassA.var2)
```

Output:

```
var1 is: Two Drops
Enter a new value for var1: Three Drops
var1 is: Three Drops
Enter a value for the new attribute var2: Four Drops
Four Drops
```
