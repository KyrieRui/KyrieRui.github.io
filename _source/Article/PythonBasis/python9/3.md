# 3. Main Modules and Non-Main Modules #

## 1. What Main and Non-Main Modules Are ##

With Python functions, if a function calls other functions to do a job, we call it a **main function**. If a function doesn't call other functions, we call it a **non-main function**. Main and non-main modules are similar: if a module is run **directly** and not used by anyone else, we call it the **main module**. If a module is **imported** by another one, we call it a **non-main module**.

## 2. The __name__ Attribute ##

Python has main modules and non-main modules, so of course we need a way to tell them apart. How?

We use the `__name__` attribute. `__name__` is a variable that Python sets for us. We can use it to check whether a module is the main module. If its value is `'__main__'`, then this module is the main module, and if not, it isn't. But note: **`__name__` being `'__main__'` only helps us CHECK whether it's the main module. It doesn't DECIDE whether it's the main module. What decides it is only whether the module was imported by someone else.**

Let's look at an example:

First we create a module called `lname`, and check whether it's the main module. If it is, print `main`; if not, print `not main`. When we run this module directly, it's being used directly and not imported by anyone, so it's the main module, and it prints `main`:

The code in `com/Learn/module/nameattributes/lname.py`:

```python
#!/usr/bin/env python
# -*- coding: UTF-8 -*-

if __name__ == '__main__':
    print('main')
else:
    print('not main')
```

Run `lname.py` directly. Output:

```
main
```


Then we create another module, `user_lname`, which simply imports the `lname` module. When we run it, the output is `not main`, because `lname` was imported by this module, so it's not the main module:


The code in `com/Learn/module/nameattributes/user_lname.py`:

<!-- skip-ci -->
```python
#!/usr/bin/env python
# -*- coding: UTF-8 -*-

import lname   # Import the lname module
```

Run `user_lname.py`. Output:

```
not main
```
