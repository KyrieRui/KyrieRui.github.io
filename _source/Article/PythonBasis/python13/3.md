# Processes #

Multithreading in Python isn't really true multithreading. If you want to make full use of a multi-core CPU, in Python you usually need to use **multiple processes**.

Python has a really handy package for multiple processes called `multiprocessing`. You just define a function, and Python does everything else.

With this package, it's easy to go from one process to running things in parallel. `multiprocessing` supports child processes, communication and shared data, and different kinds of synchronisation. It provides parts like `Process`, `Queue`, `Pipe` and `Lock`.


## 1. The Process Class ##

The class for creating a process: `Process([group [, target [, name [, args [, kwargs]]]]])`

* `target` is the thing to call
* `args` is a tuple of positional arguments for it
* `kwargs` is a dictionary of keyword arguments for it
* `name` is a nickname
* `group` isn't really used

Here's an example that creates a function and runs it in several processes:

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

import multiprocessing
import time


def worker(interval, name):
    print(name + '[start]')
    time.sleep(interval)
    print(name + '[end]')


if __name__ == "__main__":
    p1 = multiprocessing.Process(target=worker, args=(2, 'Two Drops 1'))
    p2 = multiprocessing.Process(target=worker, args=(3, 'Two Drops 2'))
    p3 = multiprocessing.Process(target=worker, args=(4, 'Two Drops 3'))

    p1.start()
    p2.start()
    p3.start()

    print("The number of CPU is:" + str(multiprocessing.cpu_count()))
    for p in multiprocessing.active_children():
        print("child   p.name:" + p.name + "\tp.id" + str(p.pid))
    print("END!!!!!!!!!!!!!!!!!")

```

Output:

```
The number of CPU is:4
child   p.name:Process-3    p.id7600
child   p.name:Process-2    p.id5560
child   p.name:Process-1    p.id7716
END!!!!!!!!!!!!!!!!!
Two Drops 1[start]
Two Drops 2[start]
Two Drops 3[start]
Two Drops 1[end]
Two Drops 2[end]
Two Drops 3[end]

Process finished with exit code 0
```


## 2. Making a Process into a Class ##

We can also make a process into a class. In the example below, when process `p` calls `start()`, the `run()` method is called automatically.


<!-- skip-ci -->
```python
# -*- coding: UTF-8 -*-

import multiprocessing
import time


class ClockProcess(multiprocessing.Process):
    def __init__(self, interval):
        multiprocessing.Process.__init__(self)
        self.interval = interval

    def run(self):
        n = 5
        while n > 0:
            print(f"Current time: {time.ctime()}")
            time.sleep(self.interval)
            n -= 1


if __name__ == '__main__':
    p = ClockProcess(3)
    p.start()

```

Output:

```
Current time: Mon Oct  9 17:26:16 2017
Current time: Mon Oct  9 17:26:19 2017
Current time: Mon Oct  9 17:26:22 2017
Current time: Mon Oct  9 17:26:25 2017
Current time: Mon Oct  9 17:26:28 2017

Process finished with exit code 0
```

## 3. The daemon Attribute ##

To see what the `daemon` attribute does, look at these two examples – one with `daemon` and one without – and compare the output.

Without the `daemon` attribute:

```python
# -*- coding: UTF-8 -*-
import multiprocessing
import time


def worker(interval):
    print(f'Work start time: {time.ctime()}')
    time.sleep(interval)
    print(f'Work end time: {time.ctime()}')


if __name__ == '__main__':
    p = multiprocessing.Process(target=worker, args=(3,))
    p.start()
    print('[END]')

```

Output:

```txt
[END]
Work start time: Mon Oct  9 17:47:06 2017
Work end time: Mon Oct  9 17:47:09 2017
```

Now add the `daemon` attribute to process `p` in the same example:

```python
# -*- coding: UTF-8 -*-

import multiprocessing
import time


def worker(interval):
    print(f'Work start time: {time.ctime()}')
    time.sleep(interval)
    print(f'Work end time: {time.ctime()}')


if __name__ == '__main__':
    p = multiprocessing.Process(target=worker, args=(3,))
    p.daemon = True
    p.start()
    print('[END]')
```

Output:

```txt
[END]
```


From the output, you can see that if a child process has `daemon` set, it ends when the main process ends. That's why the child process's messages weren't printed.


## 4. The join Method ##

Carrying on from the example above: what if we want the child process to finish?

We can use the `join` method. Its main job is to **block** the current process until the process that called `join` has finished, and then carry on with the current process.

Here's the example with `join` added:

```python
import multiprocessing
import time


def worker(interval):
    print(f'Work start time: {time.ctime()}')
    time.sleep(interval)
    print(f'Work end time: {time.ctime()}')


if __name__ == '__main__':
    p = multiprocessing.Process(target=worker, args=(3,))
    p.daemon = True
    p.start()
    p.join()
    print('[END]')
```

Output:

```txt
Work start time: Tue Oct 10 11:30:08 2017
Work end time: Tue Oct 10 11:30:11 2017
[END]
```

## 5. Pool ##

If we need lots of child processes, do we have to create them one by one?

Of course not! We can use a **process pool** to create child processes in bulk.

Example:

```python
# -*- coding: UTF-8 -*-

from multiprocessing import Pool
import os, time, random


def long_time_task(name):
    print(f'Process name: {name}; process PID: {os.getpid()} ')
    start = time.time()
    time.sleep(random.random() * 3)
    end = time.time()
    print(f'Process {name} ran for {end - start} seconds')


if __name__ == '__main__':
    print(f'Main process PID: {os.getpid()}')
    p = Pool(4)
    for i in range(6):
        p.apply_async(long_time_task, args=(i,))
    p.close()
    # Wait for all child processes to finish before ending the main process
    p.join()
    print('[End]')
```

Output:

```txt
Main process PID: 7256
Process name: 0; process PID: 1492
Process name: 1; process PID: 12232
Process name: 2; process PID: 4332
Process name: 3; process PID: 11604
Process 2 ran for 0.6500370502471924 seconds
Process name: 4; process PID: 4332
Process 1 ran for 1.0830621719360352 seconds
Process name: 5; process PID: 12232
Process 5 ran for 0.029001712799072266 seconds
Process 4 ran for 0.9720554351806641 seconds
Process 0 ran for 2.3181326389312744 seconds
Process 3 ran for 2.5331451892852783 seconds
[End]
```

One thing to note: calling `join()` on a `Pool` object waits for all child processes to finish. You must call `close()` before `join()`, and after `close()` you can't add any new processes.

Look carefully at the output. Child processes 0, 1, 2 and 3 start straight away, but child process 4 has to wait until one of the earlier ones finishes. That's because the default size of `Pool` on my computer is 4, so at most 4 processes run at the same time. This is a limit `Pool` sets on purpose – it's not a limit of the operating system. If you change it to:

<!-- skip-ci -->
```python
p = Pool(5)
```

then 5 processes can run at the same time.



## 6. Communication Between Processes ##

Processes definitely need to talk to each other. The operating system provides many ways for processes to communicate. Python's `multiprocessing` module wraps these low-level mechanisms and gives you several ways to exchange data, like `Queue` and `Pipes`.

Take `Queue` as an example. In the parent process, we create two child processes: one writes data into the `Queue`, and the other reads data from it:

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

from multiprocessing import Process, Queue
import os, time, random


def write(q):
    # The process that writes data
    print(f'Writer process PID: {os.getpid()}')
    for value in ['Two Drops', 'Three Drops', 'Four Drops']:
        print(f'Value written to the Queue: {value}')
        q.put(value)
        time.sleep(random.random())


def read(q):
    # The process that reads data
    print(f'Reader process PID: {os.getpid()}')
    while True:
        value = q.get(True)
        print(f'Value read from the Queue: {value}')


if __name__ == '__main__':
    # The parent process creates the Queue and passes it to each child process
    q = Queue()
    pw = Process(target=write, args=(q,))
    pr = Process(target=read, args=(q,))
    # Start child process pw
    pw.start()
    # Start child process pr
    pr.start()
    # Wait for pw to finish
    pw.join()
    # pr has an endless loop, so we can't wait for it to finish – we have to force it to stop
    pr.terminate()

```

Output:

```txt
Reader process PID: 13208
Writer process PID: 10864
Value written to the Queue: Two Drops
Value read from the Queue: Two Drops
Value written to the Queue: Three Drops
Value read from the Queue: Three Drops
Value written to the Queue: Four Drops
Value read from the Queue: Four Drops
```
