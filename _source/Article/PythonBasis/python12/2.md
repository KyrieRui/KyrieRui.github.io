# 2. Using `type()` to Create Classes on the Fly #

Because classes are objects, we can create classes **while the program is running**.

Python is a dynamic language.

**The biggest difference between dynamic and static languages is that functions and classes aren't defined when the code is compiled – they're created dynamically while the program runs.**

First, let's get to know the `type()` function.


Create a module called `hello.py`, and define a class called `Hello`:

```python
class Hello(object):
    def hello(self, name='Py'):
        print('Hello,', name)
```

Then, in another module, import the `hello` module and print some information.

The `type()` function lets you see the type of a class or a variable.

<!-- skip-ci -->
```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

from com.twowater.hello import Hello

h = Hello()
h.hello()

print(type(Hello))
print(type(h))

```

What will the output be?

```
Hello, Py
<class 'type'>
<class 'com.twowater.hello.Hello'>
```

As we said, `type()` shows the type of a class or variable. `Hello` is a class, and its type is `type`. `h` is an instance, and its type is `com.twowater.hello.Hello`.

The `com.twowater` part at the front is my package name; the `hello` module lives in that package.

Let's think about this a bit more. In the example above, we used `type()` to see the type of something.

When we looked at the type of the `Hello` class, it printed `<class 'type'>`.

**In fact, `type()` can not only return the type of an object – it can also create new types.**

Classes are created dynamically at runtime, and the way to create a class is with the `type()` function.

For example, we can use `type()` to create the `Hello` class from above. Look at this code:

```python
# -*- coding: UTF-8 -*-

def printHello(self, name='Py'):
    # A function that prints Hello
    print('Hello,', name)


# Create a Hello class
Hello = type('Hello', (object,), dict(hello=printHello))

# Create an instance of Hello
h = Hello()
# Call the Hello class's method
h.hello()
# Look at the type of the Hello class
print(type(Hello))
# Look at the type of instance h
print(type(h))

```

Output:

```
Hello, Py
<class 'type'>
<class '__main__.Hello'>
```

Here's what the arguments mean when you create a class with `type()`:

1. The name of the class – in the example, `Hello`

2. A tuple of parent classes. Python supports multiple inheritance. If there's only one parent, use the one-element tuple form. In the example, it inherits from `object`, so it's written `(object,)`

3. A dictionary linking method names to functions. In the example, the function `printHello` is linked to the method name `hello`

The general pattern is:

<!-- skip-ci -->
```python
type(class_name, tuple_of_parent_classes (can be empty), dict_of_attributes (names and values))
```

Now that we understand the arguments, look at the output: a class made with `type()` is exactly the same as one written with `class`.

This is because when the Python interpreter sees a `class` definition, it just reads the syntax, and then calls `type()` to create the class.

Normally, we define classes with `class ***...`, but `type()` can create classes too.

This means a dynamic language can create classes while running. This is very different from static languages. To create a class while a static language program is running, you'd have to build a string of source code and call the compiler, or use tools to generate bytecode. That's basically dynamic compiling, and it's very complicated.

**So you can see: in Python, classes are objects too, and you can create classes dynamically.**

This is actually what Python does behind the scenes when you use the `class` keyword – and it does it using **metaclasses**.
