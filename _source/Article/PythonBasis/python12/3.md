# 3. What is a Metaclass? #

After all that, we've finally (sort of) arrived at metaclasses. But we still don't know what on earth a metaclass is.

When we create a class, it's usually so we can create instances (objects) of it.

So what's a metaclass for?

**A metaclass is used to create classes. Another way to think about it: a metaclass is the class of a class.**

From the `type()` introduction above, we know we can create a class with `type()`:

```python	
MyClass = type('MyClass', (), {})
```

**In fact, `type` is a metaclass.**

`type` is the metaclass Python uses behind the scenes to create **all** classes.

Now we can guess why it's `type` and not `Type`.

Probably to match `str` – `str` is the class that creates string objects, and `int` is the class that creates integer objects.

`type` is the class that creates class objects.

You can see this by checking the `__class__` attribute.

**Everything** in Python – yes, everything – is an object.

That includes integers, strings, functions and classes. They're all objects, and they're all created from a class.

```python
# Integer
age = 23
print(age.__class__)
# String
name = 'Two Drops'
print(name.__class__)


# Function
def fu():
    pass


print(fu.__class__)


# Instance
class eat(object):
    pass


mEat = eat()

print(mEat.__class__)
```

Output:

```
<class 'int'>
<class 'str'>
<class 'function'>
<class '__main__.eat'>
```

You can see that all of these – all objects – were created by a class. So you might wonder: what's the `__class__` of the `__class__`?

**In other words, what's the class that creates these classes?**

Let's add this code to the code above:

<!-- skip-ci -->
```python
print(age.__class__.__class__)
print(name.__class__.__class__)
print(fu.__class__.__class__)
print(mEat.__class__.__class__)
```

Output:

```
<class 'type'>
<class 'type'>
<class 'type'>
<class 'type'>
```

Look carefully and think it through. The output above is the `__class__` of the `__class__` of the integer `age`, the string `name`, the function `fu` and the instance `mEat`.

You could also say it's the class of their class. And every one printed `type`.

As we said at the start, a metaclass is the class of a class.

So a metaclass is something that creates classes.

You can also think of it as: a metaclass is what **makes** classes.

**And `type` is the built-in metaclass – the metaclass that comes with Python.**




## First tell objects and classes apart, then look at the tool that makes classes

This chapter can get confusing, because we're not just creating instances – we're talking about classes themselves. Let's use three checks to lay out the relationships:

```python
StudyRecord = type('StudyRecord', (), {'category': 'Study record'})
record = StudyRecord()
print(type(record) is StudyRecord)
print(type(StudyRecord) is type)
print(record.category)
```

Output:

```text
True
True
Study record
```

The first line creates a class, and the second line uses that class to create an instance. `type(record)` checks what class the instance belongs to, and `type(StudyRecord)` goes one step further and checks the type of the class itself. In this normal example, the class was created by `type`.
