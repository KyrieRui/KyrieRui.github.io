# Boundaries and Groups

We've already spent a lot of space on the points above. Now let's introduce **boundary matchers** and **groups**.

The common boundary matchers are:

| Syntax | Description                                             |
| ---- | ------------------------------------------------ |
| ^    | Matches the start of the string (with multiple lines, the start of each line) |
| $    | Matches the end of the string (with multiple lines, the end of each line) |
| \A   | Matches only the start of the string                                 |
| \Z   | Matches only the end of the string                                 |
| \b   | Matches the boundary between \w and \W                               |
| \B   | [^\b] (not a word boundary)                                            |

**Groups**: an expression inside round brackets is a group. A group `(...)` treats those characters as one unit. You can have several groups – each new group gets the next number (1, 2, 3…). You can also put a quantifier after a group.
