# re.sub

In real work, we often need to **replace** characters in a string. That's when we use the function `def sub(pattern, repl, string, count=0, flags=0)`. `re.sub` has five parameters: three required ones – `pattern`, `repl`, `string` – and two optional ones – `count`, `flags`.

Here's what each parameter means:

| Parameter    | Description                                                          |
| ------- | ------------------------------------------------------------- |
| pattern | The regex pattern string                                        |
| repl    | Short for "replacement" – what to replace matches with                   |
| string  | The string to process, where replacements will happen                  |
| count   | Of the matches found by `pattern`, how many to replace (from the start) |
| flags   | Regex modifiers (flags)                                              |

Look at the example below – the comments explain it clearly. The main thing to notice is that the **second argument can be a function**. This is what makes `sub` so powerful. For example, the function `convert` in the example checks each matched character and replaces it with something different.

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

import re

a = 'Python*Android*Java-888'

# Replace every * in the string with &
sub1 = re.sub('\*', '&', a)
print(sub1)

# Replace only the first * in the string with &
sub2 = re.sub('\*', '&', a, 1)
print(sub2)


# Replace every * with &, and every - with |

# 1. First, define a function
def convert(value):
    group = value.group()
    if (group == '*'):
        return '&'
    elif (group == '-'):
        return '|'


# The second argument (what to replace with) can be a function
sub3 = re.sub('[\*-]', convert, a)
print(sub3)
```

Output:

```txt
Python&Android&Java-888
Python&Android*Java-888
Python&Android&Java|888
```
