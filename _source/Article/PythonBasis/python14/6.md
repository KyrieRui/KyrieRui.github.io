# re.match and re.search

**The re.match function**

Syntax:

<!-- skip-ci -->
```python
re.match(pattern, string, flags=0)
```

`re.match` tries to match a pattern **at the start** of the string. If it doesn't match at the start, `match()` returns `None`.


**The re.search function**

Syntax:

<!-- skip-ci -->
```Python
re.search(pattern, string, flags=0)
```

`re.search` scans **the whole string** and returns the first match it finds.

`re.match` and `re.search` take basically the same parameters:

| Parameter    | Description                                                     |
| ------- | -------------------------------------------------------- |
| pattern | The regular expression to match                                         |
| string  | The string to search                                           |
| flags   | Flags that control how matching works, e.g. whether it's case-sensitive |

So what's the difference?

`re.match` only matches at the **start** of the string. If the start doesn't match the regex, matching fails and it returns `None`. `re.search` searches the **whole** string until it finds a match. That's the difference.

There are lots of detailed explanations of `re.match` and `re.search` online, but personally, I prefer to use `re.findall`.

Look at the example below to compare `re.search` and `re.findall`, and to see how multiple groups work. Read the comments and compare with the output:

Example:

```python

#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

# Extract an image address

import re

a = '<img src="https://s-media-cache-ak0.pinimg.com/originals/a8/c4/9e/a8c49ef606e0e1f3ee39a7b219b5c05e.jpg">'

# Using re.search
search = re.search('<img src="(.*)">', a)
# group(0) is the whole match
print(search.group(0))
print(search.group(1))

# Using re.findall
findall = re.findall('<img src="(.*)">', a)
print(findall)

# Using several groups (e.g. we want both the img tag name and the image address)
re_search = re.search('<(.*) src="(.*)">', a)
# Print img
print(re_search.group(1))
# Print the image address
print(re_search.group(2))
# Print img and the image address together, as a tuple
print(re_search.group(1, 2))
# Or use groups()
print(re_search.groups())

```

Finally: regular expressions are a very powerful tool. They can usually solve problems that the built-in string functions can't, and most programming languages have them. Python is used for lots of things, but web scraping and data analysis especially can't do without regular expressions. So regular expressions are really important for learning Python.
