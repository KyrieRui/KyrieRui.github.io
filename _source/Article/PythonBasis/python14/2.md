# Character Sets


OK, with the examples above we've had a first look at Python regular expressions. You might ask: what other rules are there? What does each letter mean?

Don't rush. Later in this chapter there's a list of regex rules, and you can easily find these on the internet too. So for now, let's go deeper into understanding regular expressions, and talk about **character sets**.

A character set is a group of characters inside a pair of square brackets `[]`. With a character set, you can match **one** of several characters.

For example, `C[ET]O` matches **CEO** or **CTO**. So `[ET]` means one E **or** one T. `[a-z]`, which we saw above, means any one lowercase letter. Here the hyphen `-` defines a **range** of characters in a row. You can put several ranges inside, like `[0-9a-fA-F]`, which matches a single hexadecimal digit, upper or lower case. Note: the order of characters and ranges inside doesn't affect the result at all.

All of this is to show that the characters inside a character set `[]` have an **"OR"** relationship. Let's look at an example:

```Python

import re
a = 'uav,ubv,ucv,uwv,uzv,ucv,uov'

# Character sets

# Find strings where the character between u and v is a or b or c
findall = re.findall('u[abc]v', a)
print(findall)
# For letters or digits in a row, you can use -
l = re.findall('u[a-c]v', a)
print(l)

# Find strings where the character between u and v is NOT a or b or c
re_findall = re.findall('u[^abc]v', a)
print(re_findall)

```

Output:

```txt
['uav', 'ubv', 'ucv', 'ucv']
['uav', 'ubv', 'ucv', 'ucv']
['uwv', 'uzv', 'uov']
```

The example uses a **negated character set**: if you put a caret `^` right after the opening bracket `[`, the set is flipped ("not these"). Remember: a negated character set must still match **one character**. For example, `q[^u]` does **not** mean "match a q that isn't followed by a u". It means "match a q followed by a character that isn't u". Compare with the output of the example above to understand.

Regular expressions also have some built-in rules. For example, `\d` matches any digit character – it's the same as `[0-9]`. Here's an example that explains these special characters using character sets.

> For Python string regexes, Unicode rules are used by default, so `\d` can also match things like full-width digits, and `\w` isn't limited to English letters, digits and underscores. Only when you limit it to ASCII rules can you think of them as the ASCII ranges below. When writing regex patterns, prefer raw strings like `r"\d"`, so the backslash isn't handled by normal string rules.

```Python
import re

a = 'uav_ubv_ucv_uwv_uzv_ucv_uov&123-456-789'

# Shorthand character sets

# \d is like [0-9] – matches all digit characters
# \D is like [^0-9] – matches all non-digit characters
findall1 = re.findall('\d', a)
findall2 = re.findall('[0-9]', a)
findall3 = re.findall('\D', a)
findall4 = re.findall('[^0-9]', a)
print(findall1)
print(findall2)
print(findall3)
print(findall4)

# \w matches any "word" character, including underscore – like [A-Za-z0-9_]
findall5 = re.findall('\w', a)
findall6 = re.findall('[A-Za-z0-9_]', a)
print(findall5)
print(findall6)

```

Output:

```txt
['1', '2', '3', '4', '5', '6', '7', '8', '9']
['1', '2', '3', '4', '5', '6', '7', '8', '9']
['u', 'a', 'v', '_', 'u', 'b', 'v', '_', 'u', 'c', 'v', '_', 'u', 'w', 'v', '_', 'u', 'z', 'v', '_', 'u', 'c', 'v', '_', 'u', 'o', 'v', '&', '-', '-']
['u', 'a', 'v', '_', 'u', 'b', 'v', '_', 'u', 'c', 'v', '_', 'u', 'w', 'v', '_', 'u', 'z', 'v', '_', 'u', 'c', 'v', '_', 'u', 'o', 'v', '&', '-', '-']
['u', 'a', 'v', '_', 'u', 'b', 'v', '_', 'u', 'c', 'v', '_', 'u', 'w', 'v', '_', 'u', 'z', 'v', '_', 'u', 'c', 'v', '_', 'u', 'o', 'v', '1', '2', '3', '4', '5', '6', '7', '8', '9']
['u', 'a', 'v', '_', 'u', 'b', 'v', '_', 'u', 'c', 'v', '_', 'u', 'w', 'v', '_', 'u', 'z', 'v', '_', 'u', 'c', 'v', '_', 'u', 'o', 'v', '1', '2', '3', '4', '5', '6', '7', '8', '9']
```
