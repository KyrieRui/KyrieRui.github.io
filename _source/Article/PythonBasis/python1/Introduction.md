And here is how the TIOBE index changed for the Top 10 languages:

Perl, Visual Basic .NET and Delphi/Object Pascal slowly faded away.

Overall, each of these languages has its own strengths. But it's easy to see that Python has grown very fast in recent years – especially because of machine learning and data analysis, which are very popular now.

Python is a **high-level** programming language, and one of its big strengths is that you can build things quickly. Python comes with a very complete standard library. It covers networking, files, GUIs (windows and buttons), databases, text and lots more. People say Python comes with **"batteries included"**. With Python, you don't need to write lots of features from scratch – you can use ready-made ones. You can also build websites with Python. Many big websites were built with it, like YouTube, Instagram, and Douban in China. Many big companies, like Google and Yahoo, and even NASA, use Python a lot.

Of course, every language has good points and bad points, and Python is no different. So what are Python's weak points?

The first is that it **runs slowly** – very slowly compared to C. Python is an **interpreted** language. When your code runs, it is translated, line by line, into machine code that the CPU understands. This translation takes a lot of time, so it's slow. A C program is **compiled** into machine code before it runs, so it's very fast.

The second is that **your code can't be hidden**. If you share your Python program, you are really sharing your source code. Compiled languages like Java and C don't have this problem, but interpreted languages must share their source code.
