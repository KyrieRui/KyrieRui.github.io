# 4. Integrated Development Environment (IDE): PyCharm #

While you are learning, I suggest writing Python in a plain text editor, or a tool like [Sublime Text](http://www.sublimetext.com/). This helps you understand the whole process.

Of course, if you already know some programming, you can use an IDE (Integrated Development Environment) to work faster. A good choice is PyCharm. PyCharm is a Python IDE made by JetBrains. It works on macOS, Windows and Linux.

Download PyCharm here: [https://www.jetbrains.com/pycharm/download/](https://www.jetbrains.com/pycharm/download/)
