# 2. Python Iterators #

Above, we briefly introduced iteration. Iteration is one of Python's most powerful features, and it's a way to get at the elements of a collection. Now for the main topic: **iterators**. An iterator is an object that **remembers where it is** while looping through something.

An iterator starts at the first element of a collection and keeps going until every element has been visited.

An iterator can only go **forward**, never backward.

Iterators have two basic functions: `iter()` and `next()`. Strings, lists and tuples can all be used to make an iterator. You can loop through an iterator with a normal `for` statement, or with the `next()` function.

Example:

```python
# 1. Make an iterator from a string
str1 = 'liangdianshui'
iter1 = iter ( str1 )

# 2. Make an iterator from a list
list1 = [1,2,3,4]
iter2 = iter ( list1 )

# 3. Make an iterator from a tuple
tuple1 = ( 1,2,3,4 )
iter3 = iter ( tuple1 )

# Use a for loop to go through the iterator
for x in iter1 :
    print ( x , end = ' ' )

print('\n------------------------')
 
# Use next() to go through the iterator
while True :
    try :
        print ( next ( iter3 ) )
    except StopIteration :
        break

```

Output:

```txt
l i a n g d i a n s h u i 
------------------------
1
2
3
4
```
