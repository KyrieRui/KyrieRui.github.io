# 1. Iteration #

What is **iteration**?

In Java, for example, we use index numbers to go through the elements of a List. In Python, given a list or tuple, we can use a `for` loop to go through it. Going through things one by one like this is called **iteration**.

But Python's `for` loop is more general than Java's `for` loop. Why? Because Python's `for` loop doesn't only work on lists and tuples – it works on any other **iterable** object too.

In other words, anything that is iterable can be looped over, whether it has index numbers or not.

For example:

```python

# -*- coding: UTF-8 -*-

# 1. Use a for loop to go through a string
for char in 'liangdianshui' :
    print ( char , end = ' ' )

print('\n')

# 2. Use a for loop to go through a list
list1 = [1,2,3,4,5]
for num1 in list1 :
    print ( num1 , end = ' ' )

print('\n')

# 3. A for loop can also go through a dict
dict1 = {'name':'Two Drops','age':'23','sex':'Male'}

for key in dict1 :    # Go through the keys in the dict
    print ( key , end = ' ' )

print('\n')

for value in dict1.values() :   # Go through the values in the dict
	print ( value , end = ' ' )

print ('\n')

# If each element in a list has two parts, that's easy to loop through too
for x , y in [ (1,'a') , (2,'b') , (3,'c') ] :
	print ( x , y )

```

Output:

```txt
l i a n g d i a n s h u i 

1 2 3 4 5 

name age sex 

Two Drops 23 Male 

1 a
2 b
3 c
```
