# 5. Examples Using Iterators and Generators Together #

Iterators and generators are closely connected, so some ideas need to be looked at together.

## 1. Looping Backwards ##

Looping backwards is something you'll often need. In the first iteration example, we printed the elements of a list from 1 to 5:

```python
list1 = [1,2,3,4,5]
for num1 in list1 :
    print ( num1 , end = ' ' )
```

What about from 5 to 1? That's easy too. Python has a built-in function `reversed()`:

```python
list1 = [1,2,3,4,5]
for num1 in reversed(list1) :
    print ( num1 , end = ' ' )
```

Looping backwards is simple, but note: **it only works if the object's size can be known in advance, or if the object has a special `__reversed__()` method. If neither is true, you must first turn the object into a list.**

Often, we can make a custom class loop backwards by giving it a `__reversed__()` method. Some of this hasn't been covered in earlier chapters yet, but have a look anyway. If you have some programming experience, you should be able to follow after learning the above.

```python
# -*- coding: UTF-8 -*-

class Countdown:
    def __init__(self, start):
        self.start = start

    def __iter__(self):
    	# Forward iterator
        n = self.start
        while n > 0:
            yield n
            n -= 1

    def __reversed__(self):
    	# Reverse iterator
        n = 1
        while n <= self.start:
            yield n
            n += 1

for rr in reversed(Countdown(30)):
    print(rr)
for rr in Countdown(30):
    print(rr)
```

The output is 1 to 30, then 30 to 1 – first in the reversed order, then in the normal order.

## 2. Looping Through Several Sequences at Once ##

Do you want to loop through several sequences at the same time, taking one element from each one each time? Have you needed that?

To loop through several sequences at once, use the `zip()` function. Example:

```python
# -*- coding: UTF-8 -*-

names = ['laingdianshui', 'twowater', 'Two Drops']
ages = [18, 19, 20]
for name, age in zip(names, ages):
     print(name,age)
```

Output:

```txt
laingdianshui 18
twowater 19
Two Drops 20
```

`zip(a, b)` makes an iterator that gives back tuples `(x, y)`, where `x` comes from `a` and `y` comes from `b`. As soon as one of the sequences reaches its end, the loop stops. So the number of loops is the length of the **shortest** sequence. Make sure you understand this: if `a` and `b` are different lengths, it goes by the shortest one and stops when that one runs out.

With `zip()`, we can also turn a list of keys and a list of values into a dict:

```python
# -*- coding: UTF-8 -*-

names = ['laingdianshui', 'twowater', 'Two Drops']
ages = [18, 19, 20]

dict1= dict(zip(names,ages))

print(dict1)

```


Output:

```python
{'laingdianshui': 18, 'twowater': 19, 'Two Drops': 20}
```

One more thing: `zip()` can take more than two sequences – not just two.
