# 2. Return Values #

From what we've learned, the `return [expression]` statement exits a function and can send a value back to the caller.

**A `return` statement with no value returns `None`.**

Here's an example:

```python
# -*- coding: UTF-8 -*-

def sum(num1,num2):
	# Sum of two numbers
	if not (isinstance (num1,(int ,float)) and isinstance (num2,(int ,float))):
		raise TypeError('Wrong argument type')
	return num1+num2

print(sum(1,2))
```

Result:

```txt
3
```

This example also uses the built-in function `isinstance()` to check data types. It checks whether the arguments are integers or floats. If not, it raises an error with the message `Wrong argument type`, like this:

A function can also return **several** values. Here's an example:

```python
# -*- coding: UTF-8 -*-

def  division ( num1, num2 ):
	# Find the quotient and the remainder
         a = num1 % num2
         b = (num1-a) / num2
         return b , a

num1 , num2 = division(9,4)
tuple1 = division(9,4)

print (num1,num2)
print (tuple1)
```

Output:

```txt
2.0 1
(2.0, 1)
```

Look closely. The first output makes it look like several values were returned. But actually, Python first made a **tuple**, and then returned that.

Remember: you can make a tuple just by using commas. Look at the `return` in the example – we're really using commas to make a tuple.

In Python, a function can return several values, which many other languages can't do. This is one way Python is simpler and more flexible than other languages.

**When Python returns several values at once, the data type is a tuple.**
