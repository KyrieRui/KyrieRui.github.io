# 3. Controlling Attribute Access #

We said before that Python doesn't have real private attributes. This makes it harder to "wrap up" (encapsulate) Python classes. Sometimes we want private attributes in Python, with public `get` and `set` methods to access them. Python can actually do this kind of wrapping with magic methods.

|Method|What it does|
| ---| --- |
|`__getattr__(self, name)`|Defines what happens when you try to access an attribute that **doesn't exist**. So by overriding it, you can catch spelling mistakes and redirect them, or warn about old attributes that shouldn't be used any more.|
|`__setattr__(self, name, value)`|Defines what happens when you assign or change an attribute. It lets you assign to an attribute whether it exists or not. Be careful: when you write `__setattr__`, avoid **infinite recursion** errors.|
|`__delattr__(self, name)`|`__delattr__` is a lot like `__setattr__`, but it defines what happens when you **delete** an attribute. When writing `__delattr__`, also avoid infinite recursion errors.|
|`__getattribute__(self, name)`|`__getattribute__` defines what happens **every** time an attribute is accessed. By comparison, `__getattr__` only works when the attribute doesn't exist. So in Python versions that support `__getattribute__`, it is always called before `__getattr__`. `__getattribute__` must also avoid infinite recursion errors.|

From the table, you can see it's easy to make a mistake when controlling attribute access. Look at this example:

```python
def __setattr__(self, name, value):
    self.name = value
    # Every time an attribute is assigned, __setattr__() is called, so this calls itself again (recursion).
    # It means self.__setattr__('name', value) runs, and each time the method calls itself. This will crash the program.

def __setattr__(self, name, value):
    # Store the value under the attribute name in the class's dictionary
    self.__dict__[name] = value  
    # Custom behaviour goes here
```

Here's an example that calls all of these methods:

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class User(object):
    def __getattr__(self, name):
        print('__getattr__ was called')
        return super(User, self).__getattr__(name)

    def __setattr__(self, name, value):
        print('__setattr__ was called')
        return super(User, self).__setattr__(name, value)

    def __delattr__(self, name):
        print('__delattr__ was called')
        return super(User, self).__delattr__(name)

    def __getattribute__(self, name):
        print('__getattribute__ was called')
        return super(User, self).__getattribute__(name)


if __name__ == '__main__':
    user = User()
    # Setting an attribute calls __setattr__
    user.attr1 = True
    # The attribute exists, so only __getattribute__ is called
    user.attr1
    try:
        # The attribute doesn't exist: first __getattribute__, then __getattr__
        user.attr2
    except AttributeError:
        pass
    # __delattr__ is called
    del user.attr1

```

Output:

```txt
__setattr__ was called
__getattribute__ was called
__getattribute__ was called
__getattr__ was called
__delattr__ was called
```
