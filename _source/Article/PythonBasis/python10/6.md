# 6. Magic Methods for Operators #


There are really a lot of magic methods for operators, so we'll just list two groups:


## 1. Comparison Operators ##

|Magic method|What it does|
|-----|-----|
|`__cmp__(self, other)`|If it returns a negative number, `self < other`; a positive number means `self > other`; 0 means `self == other`. Defining `__cmp__` is strongly **not** recommended. Instead, define `__lt__`, `__eq__` and so on separately. `__cmp__` was removed in Python 3.|
|`__eq__(self, other)`|Defines how `==` behaves|
|`__ne__(self, other)`|Defines how `!=` behaves|
|`__lt__(self, other)`|Defines how `<` behaves|
|`__gt__(self, other)`|Defines how `>` behaves|
|`__le__(self, other)`|Defines how `<=` behaves|
|`__ge__(self, other)`|Defines how `>=` behaves|


A simple example makes it clear:

> Look at the line labelled `num1 != num2` below: inside the curly braces it actually still says `num1 == num2`, so the current code calls `__eq__`. To really test "not equal", change that expression to `num1 != num2`. Then `__ne__` is called and you get `True`.

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class Number(object):
    def __init__(self, value):
        self.value = value

    def __eq__(self, other):
        print('__eq__')
        return self.value == other.value

    def __ne__(self, other):
        print('__ne__')
        return self.value != other.value

    def __lt__(self, other):
        print('__lt__')
        return self.value < other.value

    def __gt__(self, other):
        print('__gt__')
        return self.value > other.value

    def __le__(self, other):
        print('__le__')
        return self.value <= other.value

    def __ge__(self, other):
        print('__ge__')
        return self.value >= other.value


if __name__ == '__main__':
    num1 = Number(2)
    num2 = Number(3)
    print(f'num1 == num2 ? --------> {num1 == num2} \n')
    print(f'num1 != num2 ? --------> {num1 == num2} \n')
    print(f'num1 < num2 ? --------> {num1 < num2} \n')
    print(f'num1 > num2 ? --------> {num1 > num2} \n')
    print(f'num1 <= num2 ? --------> {num1 <= num2} \n')
    print(f'num1 >= num2 ? --------> {num1 >= num2} \n')

```

Output:

```txt
__eq__
num1 == num2 ? --------> False

__eq__
num1 != num2 ? --------> False

__lt__
num1 < num2 ? --------> True

__gt__
num1 > num2 ? --------> False

__le__
num1 <= num2 ? --------> True

__ge__
num1 >= num2 ? --------> False

```

## 2. Arithmetic Operators ##

|Magic method|What it does|
|-----|-----|
|`__add__(self, other)`|Addition (`+`)|
|`__sub__(self, other)`|Subtraction (`-`)|
|`__mul__(self, other)`|Multiplication (`*`)|
|`__floordiv__(self, other)`|The `//` operator|
|`___div__(self, other)`|The `/` operator. Removed in Python 3, because in Python 3, division is "true division" by default|
|`__truediv__(self, other)`|True division. In Python 3, `/` is true division by default – no need for `from __future__ import division`|
|`__mod__(self, other)`|The `%` operator (remainder)|
|`__divmod__(self, other)`|The built-in `divmod()` function|
|`__pow__(self, other)`|The `**` operator (power)|
|`__lshift__(self, other)`|The bitwise `<<` operator|
|`__rshift__(self, other)`|The bitwise `>>` operator|
|`__and__(self, other)`|The bitwise `&` operator|
|`__or__(self, other)`|The bitwise `|` operator|
|`__xor__(self, other)`|The bitwise `^` operator|
