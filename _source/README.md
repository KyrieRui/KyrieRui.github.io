# Source for the Python for Beginners site

The website in the repository root is generated. This folder keeps what it was built from.

- `Article/` – the simple-English translation of the walter201230/Python tutorial (Markdown).
- `data/exercises_en.json` – the 100 translated exercises with their checking rules.
- `translations/` – exercise translations and the extra teaching sections that only exist on learn-py.org.
- `site_src/` – the site's CSS, JavaScript, Python checker (`grader.py`) and Pyodide worker.
- `build_site.py` – turns all of the above into the static site.
