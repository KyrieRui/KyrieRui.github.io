# Python for Beginners – Simple English Edition

A simple-English translation of the Chinese Python tutorial **[walter201230/Python](https://github.com/walter201230/Python)** by walter201230 ("Two Drops" / 两点水), prepared for classroom use.

## Licence and credit

The original work is © walter201230 and is licensed under [Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). See `LICENSE`.

This edition is a translation and adaptation of that work. Changes made:

- Translated into simple English for young learners, keeping the original structure, code and examples as closely as possible
- Chinese text inside code and diagrams translated, with outputs updated to match
- Example names changed to English (e.g. 两点水 → "Two Drops", 水哥 → "Brother Shui")
- The author's WeChat promotion messages removed
- A small number of technical mistakes in the original corrected
- Mind-map pictures (`.png`) and `tiobe_trend.png` are unchanged and still contain Chinese text
